# Generative Road Modeling: Architectural Workflow Specification

This document outlines the end-to-end algorithmic pipeline for generating masterplan-scale road networks. The workflow is divided into a 7-step procedural pipeline that transitions from 2D topological graphs to fully engineered 3D terrain and infrastructure.

## Phase 1: The 2D Topological Network
The foundation of the pipeline is a flat, 2D graph representing the road centerlines and intersections.
*   **Graph Connectivity:** Solves the topological graph to ensure all nodes (intersections) and edges (road segments) are mathematically connected.
*   **Semantic Tagging (Edges):** Road segments are tagged with essential metadata: Hierarchy (Primary, Secondary, Local), Type (One-way, Two-way), Lanes, Sidewalk widths, Boulevards, and landscaped medians.
*   **Semantic Tagging (Nodes):** Intersections are tagged with priority rules, junction types (Roundabout, T-Junction, Signalized), and fillet/turning radius requirements.

## Phase 2: 2D Drafting & Data Export
Before moving to 3D, the fully tagged 2D network can be serialized.
*   **JSON Payload:** The topological graph and its metadata are exported to a JSON file.
*   **Drawing Generation:** This payload can be consumed by external tools or specific Grasshopper nodes to auto-generate precise 2D CAD drafting, masterplan documentation, and right-of-way boundaries.

## Phase 3: Initial Terrain Analysis (The Drape)
A preliminary analytical pass to evaluate the feasibility of the 2D layout against the existing 3D topography.
*   **Existing Ground (EG) Projection:** The 2D network is draped directly onto the raw Terrain Mesh (DEM/TIN).
*   **Visual Analysis:** Generates visual feedback (e.g., color-coded bar graphs) showing instant slope gradients and estimated cut/fill extremes. This allows the planner to rapidly spot areas where the 2D routing defies geographical constraints before committing to a 3D alignment.

## Phase 4: Auto-Grade (The 3D Vertical Alignment Solver)
The computational core that translates the 2D graph into civil-engineered 3D centerlines.
*   **Intersection Pinning:** Reads the tagged Nodes (Phase 1) and locks their Z-heights to the average terrain height, ensuring flat, drivable junctions.
*   **The Slope Envelope:** Steps along the draped edges and forcefully clamps the Z-heights to ensure no segment exceeds the user-defined `Max Slope` rule.
*   **Vertical Smoothing:** Applies a moving-average/NURBS rebuild to convert sharp slope limits into smooth vertical parabolas (sag and crest curves).
*   **Feedback Loop:** If the terrain is so extreme that the nodes cannot be connected without violating the `Max Slope`, the node will flag the route as impossible, prompting the planner to adjust the 2D path.

## Phase 5: Master Terrain Grader (The Road Generator)
The 3D paths generated by Auto-Grade are fed into the Terrain Grader engine.
*   **Daylight Generation:** Calculates precise mathematical raycasts from the road edges to the existing terrain based on allowable embankment slopes (e.g., 1:3).
*   **Point-Cloud Booleans & Triangulation:** Strips the original terrain mesh vertices from beneath the road footprint and uses Delaunay triangulation to flawlessly stitch the new road prism, cut slopes, and fill slopes into a unified master mesh.

## Phase 6: Parametric Geometry Generation
Dedicated nodes read the 3D curves (Phase 4) and Topologic Data (Phase 1) to construct the physical assets.
*   **Road Segments:** Extrudes the asphalt, curbs, sidewalks, and medians based on the semantic tags.
*   **Intersections:** Constructs complex junction geometry (fillets, roundabouts, crosswalks) that perfectly align with the pinned Z-heights of the 3D network.

## Phase 7: Final Simulation & Analytics
With the full 3D network and topography realized, the system runs the final analytical passes.
*   **Earthwork Balances:** Precise $m^3$ calculations for Cut and Fill volumes across the entire masterplan.
*   **Slope Validation:** Final color-coded rendering of the finished grade slopes.
*   **Circulation:** Traffic flow, connectivity analysis, and watershed/drainage simulations on the newly modified terrain.
