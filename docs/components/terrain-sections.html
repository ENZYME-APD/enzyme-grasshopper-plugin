Terrain Sections

Slices meshes into sections and unrolls them for layout.

Site Analysis Nickname: TerrSec

Overview

Slices meshes into sections and unrolls them for layout.

Inputs (8)

  • TargetMeshes (Mesh): The meshes to section.
  • RotationPlane (Plane): Orientation plane for the bounding box sectioning.
  • SectionsX (Integer): Number of sections running parallel to the X-axis.
  • SectionsY (Integer): Number of sections running parallel to the Y-axis.
  • LayoutFlat (Boolean): Toggle to generate 2D XY print layouts next to the mesh.
  • Bake (Boolean): Bake trigger
  • BakeName (Text): Bake group/layer name
  • Run (Boolean): Optional. False = skip the analysis and keep showing the last results (cached). Share one toggle with the Analysis Dashboard to switch everything on/off together.

Outputs (10)

  • SectionOutlinesX (Curve): 3D Polylines running parallel to the X-axis.
  • SectionOutlinesY (Curve): 3D Polylines running parallel to the Y-axis.
  • LabelText3D (Text): Text strings for 3D section labels.
  • LabelPlanes3D (Plane): Planes for 3D section labels.
  • FlatSectionsX (Curve): 2D X-Sections stacked downwards (-Y direction).
  • FlatSectionsY (Curve): 2D Y-Sections stacked leftwards (-X direction).
  • LabelTextFlat (Text): Text strings for the flattened section layout.
  • LabelPlanesFlat (Plane): Planes for the flattened section layout.
  • SectionMetadata (Text): Dictionary keys containing spatial transform & ID data.
  • Info (Text): Component information and interpretation

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. For each mesh, its bounding box is taken in the RotationPlane orientation. SectionsX cut planes (spanned by the plane X axis and Z axis) are placed at equal steps of width / (SectionsX + 1) along the plane Y axis, so no cut sits on the edges; SectionsY works the same way along the X axis.
  2. Each plane is intersected with the mesh (mesh-plane intersection polylines); every polyline piece goes to SectionOutlinesX or SectionOutlinesY, with X-SEC n or Y-SEC n labels 2 units beyond the first and last piece.
  3. With LayoutFlat on, each section is rotated flat into the XY plane (X sections: along-section direction to X, height to Y; Y sections: along-section to Y, height to X) and stacked beside the site, with a gap of 5 % of the overall bounding box diagonal. Section metadata (id, plane origin, direction) is output as JSON text.
  4. With Bake true, sections are baked to Site Sections::Terrain Sections and Site Sections::Unrolled Sections in a group named BakeName, replacing objects previously baked with the same BakeName.

Assumptions

  • Meshes are terrain or site models; units are model units (label offset of 2 assumes metres).
  • RotationPlane Z axis is vertical for true vertical sections.

Simplifications and limits

  • Flat sections keep only shape: their position on the sheet is relative, so absolute elevations and chainage are not kept and must be annotated separately.
  • Section positions depend on each mesh own bounding box, so with several meshes the cuts do not line up between them.

Workflow

  • Terrain mesh -> TargetMeshes; FlatSections and flat labels -> layout drawings; 3D outlines -> site model views.
