Terrain Slope

Site Analysis Nickname: TerrainSlope

Overview

Ultra-fast mesh slope analyzer using raw C# sequential array processing and safe UI automation.

Inputs (5)

  • TargetMeshes (Mesh): Meshes to analyze
  • ThresholdValue (Number): Threshold for slope analysis
  • ThresholdMode (Integer): 0: Degrees, 1: Percentage, 2: Ratio
  • Custom Colors (Colour): List of colors for gradient or binary mapping
  • EnableBinaryMode (Boolean): If true, snaps to binary colors (Under/Over threshold)

Outputs (3)

  • AnalyzedMeshes (Mesh): Colored Meshes
  • Dashboard Data (Text): JSON Legend Data
  • Info (Text): Component information and interpretation
