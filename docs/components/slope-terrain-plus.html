Slope Terrain Plus

SlopeMesh+

Ultra-fast mesh slope analyzer using raw C# sequential array processing and safe UI automation.

Description

Analyzes terrain slope using degrees, percentage, or ratio, applying a binary or gradient heatmap to the output mesh.

Inputs

NameTypeAccessDescription
TargetMeshesMeshListMeshes to analyze
ThresholdValueNumberItemThreshold for slope analysis
ThresholdModeIntegerItem0: Degrees, 1: Percentage, 2: Ratio
ColorStartColorItemColor for flat terrain
ColorEndColorItemColor for steep terrain
EnableBinaryModeBooleanItemIf true, snaps to binary colors

Outputs

NameTypeAccessDescription
AnalyzedMeshesMeshListColored Meshes
LegendColorsColorListLegend Colors
LegendValuesTextListLegend Values
OverThresholdRatioNumberListRatio of faces over threshold
