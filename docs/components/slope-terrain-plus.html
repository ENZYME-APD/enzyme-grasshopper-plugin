Slope Terrain Plus

Ultra-fast mesh slope analyzer using raw C# sequential array processing and safe UI automation.

Terrain Nickname: SlopeMesh+

Overview

Ultra-fast mesh slope analyzer using raw C# sequential array processing and safe UI automation.

Inputs (6)

  • TargetMeshes (Mesh): Meshes to analyze
  • ThresholdValue (Number): Threshold for slope analysis
  • ThresholdMode (Integer): 0: Degrees, 1: Percentage, 2: Ratio
  • ColorStart (Colour): Color for flat terrain
  • ColorEnd (Colour): Color for steep terrain
  • EnableBinaryMode (Boolean): If true, snaps to binary colors

Outputs (4)

  • AnalyzedMeshes (Mesh): Colored Meshes
  • LegendColors (Colour): Legend Colors
  • LegendValues (Text): Legend Values
  • OverThresholdRatio (Number): Ratio of faces over threshold
