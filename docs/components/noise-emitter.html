Noise Emitter From Curves

Converts line/curve paths (roads, railways) into calibrated discrete point emitters whose source levels preserve total road acoustic energy independent of divide spacing.

Site Analysis Nickname: NoiseLines

Overview

Noise Emitter From Curves transforms linear infrastructure (motorways, urban arterials, local streets, railways) into discrete point emitters ready for acoustic propagation simulation.

Unlike naive subdivision where dividing curves into more points artificially inflates noise, this component employs analytical line-source calibration. Each discretized segment's sound power is calibrated such that the energetic summation of all points precisely reconstructs the road's true equivalent continuous level (LAeq) at the specified reference distance (e.g. 10 m), exhibiting true cylindrical line-source decay (−3 dB per doubling of distance).

Presets & Calibration Physics

Built-in Road Presets (LAeq at 10 m):

  • 🚗 Highway / Expressway: 78.0 dB(A)
  • 🚙 Arterial Road: 70.0 dB(A)
  • 🚐 Local Street: 60.0 dB(A)
  • 🚶 Pedestrian / Slow Zone: 50.0 dB(A)
  • 🚆 Railway: 80.0 dB(A)

Inputs (4)

  • Curve Paths (Curve list): Centerlines representing roads, avenues, or rail corridors.
  • Average Noises (Number list): Equivalent continuous level LAeq [dB(A)] at the reference distance from each road. Automatically matches list length or re-uses the last value.
  • Divide Length (Number): Target spacing in meters between emitter points. Thanks to analytical calibration, results are invariant to this setting.
  • Reference Distance (Number, optional): Perpendicular distance in meters from the road centerline at which the input dB level applies (default: 10.0 m).

Outputs (3)

  • Points (Point list): Generated 3D emitter points along the road corridors.
  • Noise Values (Number list): Calibrated point source levels Lp at 1 m [dB(A)], ready to connect directly into the Power(dB) input of Fast Noise Analyzer.
  • Info (Text): Detailed calibration notes, active point count, and acoustic methodology.
