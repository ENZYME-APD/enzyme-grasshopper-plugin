Streamlines

Generates smooth streamlines (particle traces) through any vector field. Regular grids (e.g. Fast CFD) are read directly with bilinear interpolation; scattered points use Inverse Distance Weighting. 4th-order Runge-Kutta integration, optional speed-coloured tubes.

Site Analysis Nickname: Streamlines

Overview

Generates smooth streamlines (particle traces) through any vector field using Inverse Distance Weighting.

Inputs (11)

  • FieldPoints (Point): The locations of the vector field data
  • FieldVectors (Vector): The vectors corresponding to each FieldPoint
  • SeedPoints (Point): The starting locations for the streamlines
  • StepSize (Number): Distance to move per integration step
  • MaxSteps (Integer): Maximum number of steps per streamline (per direction)
  • SearchRadius (Number): Scattered points only: radius to search for blending local vectors (ignored for regular grids)
  • MoveUp (Number): Visual Z-offset to prevent clashing with the analysis mesh
  • Direction (Integer): 1 = both ways from each seed (default), 0 = downstream only, -1 = upstream only
  • MinSpeed (Number): Lines stop where the field is slower than this (m/s)
  • TubeRadius (Number): Radius of the speed-coloured tube mesh (0 = no tubes)
  • Palette (Text): Tube colours by local speed (palette name, e.g. Wind, Turbo, Viridis)

Outputs (5)

  • Streamlines (Curve): The generated streamline curves
  • Info (Text): Component documentation and stats
  • Speeds (Number): Local field speed at every streamline vertex (one branch per streamline)
  • Tubes (Mesh): One mesh of tubes coloured by local speed (needs TubeRadius > 0)
  • Dashboard Data (Text): JSON legend payload for the tube colours
