Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. A standard Boolean Toggle whose value is forced to False whenever the document is opened (on read).

Assumptions

  • Used as the Run input of heavy components so they do not run on file open.

Simplifications and limits

  • None beyond a normal toggle: the saved state is ignored on open.

Workflow

  • False Start Toggle -> Run of analysis components.
