Canvas Auditor

Scans the Grasshopper canvas to select components with errors, legacy/outdated components, or all Enzyme components.

Utilities Nickname: Auditor

Overview

Scans the Grasshopper canvas to select components with errors, legacy/outdated components, or all Enzyme components.

Inputs (5)

  • Select Enzyme (Boolean): Selects all Enzyme components on the canvas.
  • Select Errors (Boolean): Selects all components currently throwing errors (red nodes).
  • Select Outdated (Boolean): Selects outdated, obsolete, or unrecognized 'placeholder' components.
  • Select Disabled (Boolean): Selects all disabled components.
  • Select Preview-On (Boolean): Selects all components with preview toggled ON.

Outputs (1)

  • Report (Text): Audit results of the current canvas.

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. Counts all objects on the canvas: Enzyme components (category Enzyme), objects with an Error message, outdated ones (Obsolete or placeholder for a missing plug-in), disabled ones (Locked) and preview-on ones (preview-capable and not hidden).
  2. When any input is True, the selection is cleared and every object in the chosen groups is selected; the Report lists the counts.

Assumptions

  • Buttons are wired to the inputs, so a selection is made once per click.

Simplifications and limits

  • Warnings are not counted as errors; groups, panels and other objects are included in Total Objects.
