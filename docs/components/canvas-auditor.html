Canvas Auditor

Scans the Grasshopper canvas to select components with errors, legacy/outdated components, or all Enzyme components.

Utilities Nickname: Auditor

Overview

Scans the Grasshopper canvas to select components with errors, legacy/outdated components, or all Enzyme components.

Inputs (5)

  • Select Enzyme (Boolean): Selects all Enzyme components on the canvas.
  • Select Errors (Boolean): Selects all components currently throwing errors (red nodes).
  • Select Outdated (Boolean): Selects outdated, obsolete, or unrecognized 'placeholder' components.
  • Select Disabled (Boolean): Selects all disabled components.
  • Select Preview-On (Boolean): Selects all components with preview toggled ON.

Outputs (1)

  • Report (Text): Audit results of the current canvas.
