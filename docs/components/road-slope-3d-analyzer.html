Terrain Nickname: RoadSlope3D

Overview

Evaluates slope compliance directly on 3D curves. Supports Threshold Modes (Degrees, Percentage, Ratio) and exports JSON dashboard data.

Inputs (3)

  • Road Curve (Curve): 3D road centerline
  • Threshold Mode (Integer): 0: Degrees, 1: Percentage, 2: Ratio
  • Max Slope (Number): Maximum allowed slope threshold

Outputs (3)

  • Pass Curves (Curve): Segments that pass the threshold
  • Fail Curves (Curve): Segments that fail the threshold
  • Dashboard JSON (Text): JSON export of analytical volumes and slopes
