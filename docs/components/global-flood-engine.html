Global Flood Engine

Simulates rainfall accumulation pooling into local valleys and depressions.

Site Analysis Nickname: GlobalFlood

Overview

Simulates rainfall accumulation pooling into local valleys and depressions.

Inputs (6)

  • TerrainMesh (Mesh): Input Terrain Mesh
  • Rainfall (Number): Rainfall intensity in Liters/m2/hour (mm/h)
  • Duration (Number): Duration of the rain event in hours
  • Iterations (Integer): Simulation steps for water flow
  • Runoff Coefficient (Number): Multiplier for rainfall (0.0 to 1.0). 1.0 = concrete (no absorption). Can be a single value or a list matching the mesh vertices.
  • Boundary Condition (Integer): 0 = Closed (water pools at edges), 1 = Open (water drains off edges)

Outputs (4)

  • FloodMesh (Mesh): Flooded terrain heatmap mesh
  • WaterDepths (Number): Water depths at each vertex in meters
  • AnalysisPoints (Point): Points corresponding to the water depth values
  • Info (Text): Component information and interpretation
