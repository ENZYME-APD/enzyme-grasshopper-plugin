3D Road Slope Analysis

Analyzes road slopes directly from 3D centerline curves without needing a terrain mesh.

Masterplan Nickname: RoadSlope3D

Overview

Analyzes road slopes directly from 3D centerline curves without needing a terrain mesh.

Inputs (5)

  • Curves (Curve): 3D curves representing road centerlines
  • Threshold (Number): Slope threshold
  • Segment Size (Number): Size of segments for analysis
  • Threshold Mode (Integer): 0: Degrees, 1: Percentage, 2: Ratio 1:X
  • Colors (Colour): Custom colors (Compliant, Non-Compliant)

Outputs (7)

  • Analyzed Segments (Curve): Segmented 3D road curves
  • Slope Values (Number): Slope values for each segment
  • Center Points (Point): Center points of segments
  • Segment Status (Text): Status (Compliant / Non-Compliant) per segment
  • Compliance Percentage (Number): Overall compliance percentage
  • Dashboard Data (Text): JSON legend data
  • Info (Text): Component information

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. Each curve is cut into N = ceil(length / Segment Size) equal-length pieces (trimmed sub-curves, so actual piece length is at most Segment Size).
  2. Slope per segment uses the straight chord between the segment end points: horizontal distance H in plan and absolute height change V; degrees = atan(V / H), percent = V / H × 100, ratio = H / V (1:X).
  3. A segment is Compliant if slope ≤ Threshold (degrees or percent) or ratio ≥ Threshold (ratio mode, flat segments always compliant). Compliance % is the share of compliant segments over all curves.
  4. Outputs the 3D segments, slopes, mid-length points and status per curve branch, plus a Binary legend payload using Colors (default lime green and red).

Assumptions

  • Curves are 3D road centrelines already at their design levels, in metres.
  • Threshold is in the units chosen by Mode (default 8 %).

Simplifications and limits

  • Slope is the chord slope over each segment, so short steep pieces inside a segment are averaged out; uphill and downhill are not distinguished.
  • Only longitudinal slope; no cross-fall, curvature or vertical curve checks. Colors only feed the legend; segments are not coloured by the component.

Workflow

  • 3D centrelines -> Curves; Status -> colour the Segments with a Custom Preview; Dashboard Data -> Legend Geometry or Analysis Dashboard.
