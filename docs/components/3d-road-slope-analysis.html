3D Road Slope Analysis

Analyzes road slopes directly from 3D centerline curves without needing a terrain mesh.

Masterplan Nickname: RoadSlope3D

Overview

Analyzes road slopes directly from 3D centerline curves without needing a terrain mesh.

Inputs (5)

  • Curves (Curve): 3D curves representing road centerlines
  • Threshold (Number): Slope threshold
  • Segment Size (Number): Size of segments for analysis
  • Threshold Mode (Integer): 0: Degrees, 1: Percentage, 2: Ratio 1:X
  • Colors (Colour): Custom colors (Compliant, Non-Compliant)

Outputs (7)

  • Analyzed Segments (Curve): Segmented 3D road curves
  • Slope Values (Number): Slope values for each segment
  • Center Points (Point): Center points of segments
  • Segment Status (Text): Status (Compliant / Non-Compliant) per segment
  • Compliance Percentage (Number): Overall compliance percentage
  • Dashboard Data (Text): JSON legend data
  • Info (Text): Component information
