Elevation Label

Custom text/elevation labels with radial rotation and auto-sync.

Site Analysis Nickname: ElevLabel

Overview

Custom text/elevation labels with radial rotation and auto-sync.

Inputs (11)

  • Points (Point): Coordinates to label
  • LabelText (Text): Optional text override
  • Length (Number): Leader line length
  • Gap (Number): Gap between line and text
  • Style (Text): Rhino Text Style name
  • TextPlane (Integer): 0=XY, 1=XZ, 2=YZ
  • Orientation (Number): Rotation in degrees
  • Anchor (Integer): 1-9 Justification
  • Bake (Boolean): Bake toggle/button
  • BakeLayer (Text): Target bake layer
  • BakeName (Text): Substitution group ID

Outputs (4)

  • LeaderLine (Curve): Generated leader lines
  • Text (Generic): Generated text entities
  • Instructions (Text): Contract constraints
  • Info (Text): Component information and interpretation

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. For each input point it draws a vertical leader line of Length above the point and places a text entity at Length + Gap above it.
  2. The text is the LabelText for that item (or the last text of the matching branch), otherwise the point Z formatted to 2 decimals.
  3. The text plane is World XY, XZ (default) or YZ, rotated by Orientation degrees about its own normal; Anchor 1 to 9 sets the justification (default 2, bottom centre).
  4. Text height comes from the Rhino dimension style named in Style (text height × dimension scale), otherwise 2.0 model units.
  5. When Bake is True it deletes earlier objects carrying the same BakeName user string, then bakes every leader and text to BakeLayer. BakeLayer may be a nested path such as Parent::Child; missing levels are created. Without a BakeName the component uses its own id, so each bake replaces its previous bake instead of adding duplicates.

Assumptions

  • Z values are read in model units relative to the model origin; no datum or sea-level offset is applied.
  • Length, Gap, Style, TextPlane, Orientation and Anchor are read per point: the matching branch and item, or the last one available (a single value applies to all points). Bake, BakeLayer and BakeName apply to all points.

Simplifications and limits

  • Leaders are always vertical; labels do not avoid each other.

Workflow

  • Points on terrain or levels -> Points. Optional custom text -> LabelText.
