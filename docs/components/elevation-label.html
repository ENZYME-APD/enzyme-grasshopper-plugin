Elevation Label

ELEV_LABEL

Custom text/elevation labels with radial rotation and auto-sync.

Description

Generates text entities and leader lines for terrain topography. Includes safe value list automation for anchoring, planes, and Rhino dimension styles. Supports direct baking to the document.

Inputs

NameTypeAccessDescription
PointsPointTreeCoordinates to label
LabelTextTextTreeOptional text override
LengthNumberTreeLeader line length
GapNumberTreeGap between line and text
StyleTextTreeRhino Text Style name
TextPlaneIntegerTree0=XY, 1=XZ, 2=YZ
OrientationNumberTreeRotation in degrees
AnchorIntegerTree1-9 Justification
BakeBooleanTreeBake toggle/button
BakeLayerTextTreeTarget bake layer
BakeNameTextTreeSubstitution group ID

Outputs

NameTypeAccessDescription
LeaderLineCurveTreeGenerated leader lines
TextGenericTreeGenerated text entities
