CWProfile

Creates a CWProfile polyline

Facade Nickname: CWP

Overview

Creates a CWProfile polyline

Inputs (5)

  • A (Number): Dimension A
  • B (Number): Dimension B
  • dA (Number): Offset dA
  • dB (Number): Offset dB
  • R (Number): Fillet radius R

Outputs (1)

  • Polyline (Curve): Resulting Polyline

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. Builds a closed A × B rectangle in the world XY plane centred on the origin (defaults A = 0.3, B = 0.5).
  2. If R > 0 the corners are filleted with Rhino CreateFilletCornersCurve and the result is converted back to a polyline; arcs are approximated by segments using the document tolerance and angle tolerance (minimum segment 0.01).
  3. The profile is then moved by (dA, dB, 0).

Assumptions

  • The profile is drawn on world XY at the origin, ready to be placed by a sweep (for example as DetailVertical or DetailHorizontal in CurtainWallSystem).

Simplifications and limits

  • Output is always a polyline, so filleted corners are faceted.
  • If R is larger than half the smaller side, or filleting fails, sharp corners are used with a warning.

Workflow

  • CWP -> DetailVertical, DetailHorizontal or DetailCorner of CurtainWallSystem.
