Canvas Usage Info

Retrieves plug-in libraries used and counts all components being used in the definition.

Utilities Nickname: CanvasUsage

Overview

Retrieves plug-in libraries used and counts all components being used in the definition.

Inputs (1)

  • Run (Boolean): Button to update the info panels

Outputs (0)

  • None

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. When Run is True, lists every non-core plug-in library used by objects on the canvas (name and version).
  2. Counts every canvas object except groups, by category, subcategory and name, and writes the lists to two panels named PlugIns Used and All Components Used (created at fixed canvas positions if missing, otherwise updated).

Assumptions

  • Panels are found by their nickname; renaming them makes the tool create new ones.

Simplifications and limits

  • Counts include parameters, panels, sliders and the tool's own panels, not only components.
