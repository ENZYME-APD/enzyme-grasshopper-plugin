GIF Compiler

Stitches a sequence of images into an animated GIF.

Utilities Nickname: GIF

Overview

Stitches a sequence of images into an animated GIF.

Inputs (4)

  • Directory (Text): Directory containing the image sequence.
  • Prefix (Text): Prefix of the images to include (e.g. 'Turntable_').
  • FPS (Integer): Frames per second.
  • Run (Boolean): Trigger the GIF compilation.

Outputs (1)

  • FilePath (Text): Path to the compiled GIF.
