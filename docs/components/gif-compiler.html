GIF Compiler

Stitches a sequence of images into an animated GIF.

Utilities Nickname: GIF

Overview

Stitches a sequence of images into an animated GIF.

Inputs (4)

  • Directory (Text): Directory containing the image sequence.
  • Prefix (Text): Prefix of the images to include (e.g. 'Turntable_').
  • FPS (Integer): Frames per second.
  • Run (Boolean): Trigger the GIF compilation.

Outputs (1)

  • FilePath (Text): Path to the compiled GIF.

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. When Run is True it collects every PNG in Directory whose name starts with Prefix, sorts them by file name and writes them as frames of a looping animated GIF named Prefix + Animation.gif in the same folder.
  2. Frame delay = 1000 / FPS ms (integer), 8-bit colour quantisation.

Assumptions

  • Frame order follows file names, so frame numbers must be zero-padded (e.g. 0001).

Simplifications and limits

  • Only PNG files are read. GIF timing is stored in 1/100 s, so the real frame rate is rounded (24 fps plays at about 25 fps).
  • Colours are reduced to 256 per frame.

Workflow

  • Advanced Export Views or a turntable capture -> Directory and Prefix.
