Facade Module: Frames

Deep structural exoskeleton grid utilizing the robust Area-Offset Method.

Masterplan Nickname: Mod_Frames

Overview

Deep structural exoskeleton grid utilizing the robust Area-Offset Method.

Inputs (14)

  • Bounds (Curve): Input bounds curves
  • Heights (Number): Input heights
  • BayWidth (Number): Width of each bay
  • BeamWidth (Number): Width of the beam
  • BeamDepth (Number): Depth of the beam
  • ColWidth (Number): Width of the column
  • ColDepth (Number): Depth of the column
  • HasPanel (Boolean): Enable inner facade panels
  • SillHeight (Number): Height of the sill
  • HeaderDrop (Number): Header drop distance
  • SubdivWidth (Number): Subdivision width
  • FinDepth (Number): Depth of the fins
  • FlipDir (Boolean): Flip direction
  • RemoveBaseBeam (Boolean): Remove base beam

Outputs (6)

  • Beams (Brep): Output beams
  • Columns (Brep): Output columns
  • Glass (Brep): Output glass panels
  • Fins (Brep): Output fins
  • HeaderPanels (Brep): Output header panels
  • SillPanels (Brep): Output sill panels
