Mesh Terrain Analyzer

Terrain Nickname: Terrain

Overview

Analyzes mesh extremes, unrolls sections bi-directionally, and generates 3D/2D metadata labels.

Inputs (11)

  • TargetMeshes (Mesh): The meshes to analyze.
  • SearchRings (Integer): Topological radius in rings.
  • ProminenceLimit (Number): Minimum Z-delta to be considered a peak/valley.
  • CustomColors (Colour): Custom colormap list.
  • CullGlobals (Boolean): Toggle to remove the absolute highest/lowest points.
  • AvoidBoundaries (Boolean): Toggle to ignore naked edge vertices.
  • EnableHeatmap (Boolean): Toggle to compute and output the vertex heatmap mesh.
  • RotationPlane (Plane): Orientation plane for the bounding box sectioning.
  • SectionsX (Integer): Number of sections running parallel to the X-axis.
  • SectionsY (Integer): Number of sections running parallel to the Y-axis.
  • LayoutFlat (Boolean): Toggle to generate 2D XY print layouts next to the mesh.

Outputs (19)

  • Instructions (Text): Component documentation and usage manual.
  • LocalPeaks (Point): Output points for local highs.
  • PeakElevations (Number): Z-values for local highs.
  • GlobalMaxPoint (Point): Absolute highest point on the mesh.
  • GlobalMaxElevation (Number): Absolute highest Z-value.
  • LocalValleys (Point): Output points for local lows.
  • ValleyElevations (Number): Z-values for local lows.
  • GlobalMinPoint (Point): Absolute lowest point on the mesh.
  • GlobalMinElevation (Number): Absolute lowest Z-value.
  • HeatmapMeshes (Mesh): The vertex-colored duplicate mesh.
  • SectionOutlinesX (Curve): 3D Polylines running parallel to the X-axis.
  • SectionOutlinesY (Curve): 3D Polylines running parallel to the Y-axis.
  • FlatSectionsX (Curve): 2D X-Sections stacked downwards (-Y direction).
  • FlatSectionsY (Curve): 2D Y-Sections stacked leftwards (-X direction).
  • LabelText3D (Text): Text strings for 3D section labels.
  • LabelPoints3D (Point): Points for 3D section labels.
  • LabelTextFlat (Text): Text strings for the flattened section layout.
  • LabelPointsFlat (Point): Points for the flattened section layout.
  • SectionMetadata (Text): Dictionary keys containing spatial transform & ID data.
