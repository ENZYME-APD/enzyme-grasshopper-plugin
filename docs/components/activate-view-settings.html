Activate View Settings

Activates a specified Named View, Layer State, and/or Display Style in the current Rhino viewport. If an input is left blank, that setting will not be changed.

Utilities Nickname: ActView

Overview

Activates a specified Named View, Layer State, and/or Display Style in the current Rhino viewport. If an input is left blank, that setting will not be changed.

Inputs (4)

  • Run (Boolean): Wire a Button here. When pressed, activates the given settings.
  • View (Text): Optional. The exact name of the Named View to activate.
  • Display Style (Text): Optional. The name of the Display Mode (e.g., 'Rendered') to activate.
  • Layer State (Text): Optional. The name of the saved Layer State to restore.

Outputs (1)

  • Info (Text): Component information and execution status.

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. When Run is True, the active Rhino viewport restores the Named View called View, switches to the display mode whose English name matches Display Style (case-insensitive) and restores the Layer State with all layer properties.
  2. Empty inputs leave that setting unchanged; names not found raise a warning and show NOT FOUND in the status.

Assumptions

  • The names exist in the active Rhino document; right-click menu items can build Value Lists of the available names.

Simplifications and limits

  • Acts on the active viewport only. Run is not edge-triggered: a Toggle left on re-applies the settings on every solve, so wire a Button.
