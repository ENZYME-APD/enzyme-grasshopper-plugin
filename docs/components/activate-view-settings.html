Activate View Settings

Utilities Nickname: ActView

Overview

Activates a specified Named View, Layer State, and/or Display Style in the current Rhino viewport. If an input is left blank, that setting will not be changed.

Inputs (4)

  • Run (Boolean): Wire a Button here. When pressed, activates the given settings.
  • View (Text): Optional. The exact name of the Named View to activate.
  • Display Style (Text): Optional. The name of the Display Mode (e.g., 'Rendered') to activate.
  • Layer State (Text): Optional. The name of the saved Layer State to restore.

Outputs (1)

  • Info (Text): Component information and execution status.
