Masterplan Nickname: AD_CAKE

Overview

Audits pre-modeled 1-floor-high Breps. Extracts base contours and heights, heals small modeling gaps using a tolerance, and outputs the Universal Data Format for the MP Engine.

Inputs (5)

  • FloorBreps (Brep): Individual floor volumes. (MUST BE FLATTENED)
  • Programs (Text): Program assigned to each Brep.
  • TowerIDs (Text): Tower tags for stacking logic.
  • BuildingNames (Text): Building grouping tags.
  • SnapTolerance (Number): Distance to heal gaps (e.g., 0.15m).

Outputs (1)

  • JSON_Payload (Text): Universal Data Format payload
