Fast Noise Analyzer

High-speed pseudo-acoustic noise propagation engine inspired by ISO 9613-2: geometric spreading, air absorption, ground effect, Maekawa barrier diffraction, and foliage attenuation.

Site Analysis Nickname: NoiseEnv

Overview

Fast Noise Analyzer simulates environmental outdoor noise propagation from multiple emitter sources (roads, machinery, trains) onto arbitrary target meshes (building façades, terrain, public realm surfaces) and discrete probe locations.

The engine uses an ISO 9613-2 inspired engineering framework:

📐 Maekawa Barrier Diffraction

Calculates path-length difference (δ) over obstacle rooflines and berms using rubber-band convex hull profiles: Dz = 10 log10(3 + 20N).

🌿 ISO 9613-2 Foliage Attenuation

Evaluates actual ray penetration length through porous tree/vegetation volumes (Soft Context), applying continuous path-length attenuation.

🌱 Ground Absorption Effect

Incorporates ground interference attenuation Agr based on mean propagation height over terrain and acoustic ground factor G (hard vs. porous soil).

⚡ Unified Mesh Collider & Culling

Pre-merges context meshes into single accelerated spatial structures and culls distant emitters (>45 dB below dominant sources) for order-of-magnitude faster solving.

Inputs (11)

  • Run (Boolean): Execution toggle switch (displays OFF when disabled to save compute).
  • AnalysisMeshes (Mesh list): Building massing or terrain meshes to receive the vertex-colored noise heatmap.
  • ContextBuildings (Mesh list, optional): Solid obstacle meshes (buildings, barriers, berms) causing acoustic diffraction.
  • SoftContext (Mesh list, optional): Vegetation volumes for foliage path attenuation.
  • Emitters (Point list): Source coordinates (e.g. from Noise Emitter From Curves).
  • EmitterPower (Number list): Sound pressure level Lp at 1 m in dB(A) (default: 85.0).
  • AnalysisPoints (Point list, optional): Discrete inspection probe points (e.g. window centers, balconies).
  • SensorOffset (Number): Normal offset distance in meters to prevent self-shadowing by the target mesh (default: 0.2 m).
  • CustomColors (Colour list, optional): Gradient color spectrum (quiet to loud).
  • Ground (Mesh, optional): Terrain mesh used to determine propagation height for ground effect calculations.
  • GroundFactor (Number, optional): Ground factor G: 0.0 = hard paving/water, 1.0 = soft turf/lawn (default: 0.5).

Outputs (7)

  • NoiseMeshes (Mesh list): Heatmap meshes with continuous vertex colors.
  • MeshPoints (Point list): Evaluated vertex coordinate points.
  • MeshValues (Number list): Sound pressure levels in dB(A) corresponding to each mesh point.
  • AnalysisPtsOut (Point list): Pass-through of discrete test probe points.
  • AnalysisPtsValues (Number list): Evaluated dB(A) levels at the discrete probe locations.
  • DashboardData (Text / JSON): Unified JSON data payload with min, max, energetic average, and arithmetic average for the Analysis Dashboard.
  • Info (Text): Detailed acoustic disclaimer, calculation metrics, and active attenuation breakdown.
