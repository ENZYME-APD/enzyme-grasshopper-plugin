Site Analysis Nickname: NoiseEnv

Overview

A rapid pseudo-acoustic noise analysis component. Maps decibel (dB) decay over distance and occlusions onto arbitrary meshes.

Inputs (9)

  • Run (Boolean): Global execution toggle switch
  • AnalysisMeshes (Mesh): Building masses or terrain to project heatmap onto
  • ContextBuildings (Mesh): Solid meshes for hard sound occlusion (-15dB)
  • SoftContext (Mesh): Vegetation/porous meshes for minor occlusion (-5dB)
  • Emitters (Point): Noise source points (e.g., roads, machinery)
  • EmitterPower (Number): Decibel level per emitter at 1m (default 85dB)
  • AnalysisPoints (Point): Specific discrete test locations (e.g. windows) to test individually
  • SensorOffset (Number): Distance to offset sensors from surfaces to avoid self-occlusion (m)
  • CustomColors (Colour): Color spectrum override (Quiet -> Loud)

Outputs (7)

  • NoiseMeshes (Mesh): Vertex-colored meshes representing the noise heatmap
  • MeshPoints (Point): The evaluated vertex coordinates of the analysis meshes
  • MeshValues (Number): The decibel values matching the MeshPoints
  • AnalysisPtsOut (Point): Pass-through for AnalysisPoints input
  • AnalysisPtsValues (Number): Raw dB values precisely at the AnalysisPoints
  • DashboardData (Text): JSON legend data
  • Info (Text): Disclaimer on methodology and pseudo-acoustic limitations
