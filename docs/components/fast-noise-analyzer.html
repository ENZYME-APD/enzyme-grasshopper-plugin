Fast Noise Analyzer

Site Analysis Nickname: NoiseEnv

Overview

Calculates pseudo-acoustic noise propagation from emitter points onto analysis meshes, outputting a vertex-colored heatmap.

Inputs (9)

  • AnalysisMeshes (Mesh): The target meshes to colorize with noise values (e.g. context buildings or terrain)
  • NoiseEmitters (Point): Point locations of noise sources
  • EmitterdB (Number): Decibel levels corresponding to each noise emitter
  • HardContext (Mesh): Solid objects (like buildings) that block noise heavily (-15dB attenuation)
  • SoftContext (Mesh): Porous objects (like vegetation) that block noise slightly (-5dB attenuation)
  • AnalysisPoints (Point): Optional specific discrete points to analyze
  • Run (Boolean): Toggle to run the analysis
  • CustomColors (Colour): Optional gradient palette for the heatmap
  • SensorOffset (Number): Distance to push the sensors off the mesh to avoid self-occlusion (m)

Outputs (7)

  • NoiseMeshes (Mesh): Vertex-colored meshes representing the noise heatmap
  • MeshPts (Point): The evaluated vertex coordinates of the analysis meshes
  • Mesh_dB (Number): The decibel values matching the MeshPoints
  • PtsOut (Point): Pass-through for AnalysisPoints input
  • Pts_dB (Number): Raw dB values precisely at the AnalysisPoints
  • Dashboard (Text): JSON legend data for the Analysis Dashboard
  • Info (Text): Disclaimer on methodology and limitations
