Document Size to Pixels

Converts standard document sizes (A4, A3, 16:9, etc.) into pixel dimensions for use with Export Named Views.

Utilities Nickname: Doc2Px

Overview

Converts standard document sizes (A4, A3, 16:9, etc.) into pixel dimensions for use with Export Named Views.

Inputs (3)

  • Format (Text): Paper format (e.g., A4, A3, 16:9 FHD).
  • Landscape (Boolean): True for Landscape, False for Portrait. (Applies to A-series paper).
  • DPI (Integer): Print DPI to use for the calculation (default 300).

Outputs (3)

  • Width (Integer): Width in pixels.
  • Height (Integer): Height in pixels.
  • DPI (Integer): Pass-through DPI to wire into Export Views.
