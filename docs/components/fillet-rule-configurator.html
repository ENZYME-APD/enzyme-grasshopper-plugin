Fillet Rule Configurator

Compiles Grasshopper lists into a Fillet Rules JSON.

Masterplan Nickname: Fillet_Rules

Overview

Compiles Grasshopper lists into a Fillet Rules JSON.

Inputs (5)

  • DefaultRadius (Number): The base radius if no rules match.
  • RuleTypes (Text): List of target types ('Tower', 'Program', 'Building').
  • RuleMatches (Text): List of target names ('Main_Tower', 'Retail', '*').
  • RuleRadii (Number): List of radii to apply to the matched targets.
  • ExactMatch (Boolean): True = Exact, False = Contains. Defaults to True.

Outputs (2)

  • Fillet_JSON (Text): The compiled JSON string to feed into BIM_JSON.
  • Instructions (Text): Detailed usage instructions.
