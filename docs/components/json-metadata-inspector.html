JSON Metadata Inspector

Extracts all unique filter keys from any MP Engine JSON.

Masterplan Nickname: JSON_Inspect

Overview

Extracts all unique filter keys from any MP Engine JSON.

Inputs (1)

  • MP_JSON (Text): Any JSON stream (Masses, Slabs, Roofs, Railings, Facades).

Outputs (5)

  • Buildings (Text): Unique Building IDs.
  • Towers (Text): Unique Tower IDs.
  • Programs (Text): Unique Program names.
  • Types (Text): Unique element types (e.g., Roof classifications).
  • Levels (Integer): Unique floor indices, sorted numerically.
