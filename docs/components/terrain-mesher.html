Site Analysis Nickname: TerrainMesh

Overview

Builds a terrain mesh from survey points and 3D breaklines (roads, platforms, decks, plateaus). Optional site boundary trims the mesh; optional plot boundary (flat 2D curve) is draped onto the terrain and its part of the mesh extracted. Tree locations are dropped onto the ground. Optional colours shade the mesh by elevation.

Inputs (9)

  • Points (Point): Survey points (clean them first with Survey Outlier Cleaner if needed).
  • Breaklines (Curve): 3D curves the terrain must follow: road edges, platform and deck outlines, plateau edges. Closed curves replace the survey points inside them (flat platforms); open curves clear survey points within Clear Radius.
  • Spacing (Number): Distance between points sampled along breaklines and boundaries (model units). Smaller = tighter fit, heavier mesh.
  • Clear Radius (Number): Survey points closer than this (in plan) to an open breakline are ignored, so the road/deck edge is not pulled out of shape.
  • Boundary (Curve): Optional closed curve: the mesh is trimmed to it (tested in plan).
  • Plot Boundary (Curve): Optional closed curve inside the site, normally flat 2D. It is draped onto the terrain and the mesh inside it is output separately.
  • Trees (Point): Optional tree locations (any Z); they are dropped onto the terrain.
  • Colors (Colour): Optional elevation gradient (low to high). Leave empty for an uncoloured mesh.
  • Max Edge (Number): Remove triangles with a plan edge longer than this (bridges across gaps or the convex hull). 0 = off.

Outputs (5)

  • Mesh (Mesh): Terrain mesh (trimmed to Boundary if given).
  • Plot Boundary (Curve): Plot boundary draped onto the terrain.
  • Plot Mesh (Mesh): Part of the terrain mesh inside the plot boundary.
  • Trees (Point): Tree locations on the terrain (same order as input; trees outside the mesh are snapped to its nearest point).
  • Info (Text): How the component works and how to tune it.
