Vector Arrow Generator

Generates high-fidelity 2D arrow outlines and meshes from input lines with custom mode logic.

Masterplan Nickname: V-Arrow

Overview

Generates high-fidelity 2D arrow outlines and meshes from input lines with custom mode logic.

Inputs (5)

  • Lines (Line): Input lines
  • Mode (Integer): 0=End, 1=Start, 2=Double
  • BodyWidth (Number): Body Width
  • HeadWidth (Number): Head Width
  • HeadLength (Number): Head Length

Outputs (2)

  • Arrow2D (Curve): Arrow 2D Outlines
  • ArrowMesh (Mesh): Arrow Meshes

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. For each line, a rectangular shaft of BodyWidth and a triangular head of HeadWidth × HeadLength are drawn in the plan perpendicular of the line (XY), at the end (Mode 0), the start (1) or both (2). The shaft is shortened by 0.9 × HeadLength under each head so they overlap slightly.
  2. Shaft and heads are unioned into one outline (Arrow2D) and meshed as a planar boundary (ArrowMesh). Lines shorter than 1.1 × HeadLength (2.2 × HeadLength in Double mode) are skipped and counted in a remark.

Assumptions

  • Lines are horizontal or nearly so; widths and lengths are in model units.

Simplifications and limits

  • Vertical lines give a degenerate outline; any Mode other than 0 to 2 draws the shaft without heads.

Workflow

  • Movement or wind direction lines -> Lines; ArrowMesh -> Custom Preview for diagrams.
