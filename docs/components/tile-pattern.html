Tile Pattern

Generates a grid pattern (rectangular, hexagonal, triangular) within a boundary and trims cells to fit.

Facade Nickname: TilePat

Overview

Generates a grid pattern (rectangular, hexagonal, triangular) within a boundary and trims cells to fit.

Inputs (8)

  • Base Geometry (Geometry): Planar Surface, Brep, or closed Curve to fill.
  • Setout Point (Point): Optional origin point for the grid alignment. If not supplied, the centroid is used.
  • Grid Type (Text): Grid type: rectangular, offset_rectangular, hexagonal, triangular
  • Cell Width (Number): Cell width
  • Cell Height (Number): Cell height
  • Grout Width (Number): Width of the grout joint between tiles. Default 0.
  • Direction (Vector): Optional vector to align the grid's X-axis. Projects to the base plane.
  • Rotation (Number): Optional rotation angle (in degrees) applied after alignment.

Outputs (7)

  • Tile Status (Integer): 0 = full, 1 = trimmed
  • Full Count (Integer): Number of full tiles
  • Trimmed Count (Integer): Number of trimmed tiles
  • All Tiles (Curve): All grid tiles (trimmed and full)
  • Full Tiles (Curve): Tiles fully inside the boundary
  • Trimmed Tiles (Curve): Tiles partially inside the boundary
  • Info (Text): Method, assumptions, simplifications and references.

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. A plane is taken from the base: the curve's own plane, or the surface or single planar Brep face normal at its mid parameters. Its origin is the area centroid, or Setout Point projected onto the plane. Direction (projected) sets the grid X axis and Rotation turns it in degrees.
  2. Cells are generated over the boundary's bounding box in that plane. Rectangular and offset rectangular use pitch X Dim + Grout by Y Dim + Grout, offset rows shifted by half a pitch; each tile is X Dim × Y Dim.
  3. Hexagonal uses flat-topped hexagons with circumradius X Dim / 2 at spacing 0.75 × X Dim by √3/2 × X Dim; triangular uses equilateral triangles of side X Dim. Grout shrinks each tile so the joint is Grout wide; Y Dim is ignored for these two.
  4. A tile whose corners and centre are all inside the boundary is full. Otherwise, if any of these points is inside or its outline crosses the boundary, it is intersected with the boundary (curve boolean, tolerance 0.001) and the pieces are output as trimmed.
  5. Tile Status is 0 for full and 1 for each trimmed piece, in the same order as All Tiles.

Assumptions

  • The base is planar and closed; the boundary is the first joined loop of the naked edges for surfaces and Breps.
  • Grid Type is one of rectangular, offset_rectangular, hexagonal, triangular (lower case after conversion).

Simplifications and limits

  • Tiles are outline curves only, without thickness.
  • Holes in a surface or Brep are ignored.
  • Full tiles are decided from corners and centre only.

Workflow

  • Facade panel or floor surface -> Base; Full Tiles and Trimmed Tiles -> counts, areas or extrusions.
