Tile Pattern

Facade Nickname: TilePat

Overview

Generates a grid pattern (rectangular, hexagonal, triangular) within a boundary and trims cells to fit.

Inputs (8)

  • Base Geometry (Geometry): Planar Surface, Brep, or closed Curve to fill.
  • Setout Point (Point): Optional origin point for the grid alignment. If not supplied, the centroid is used.
  • Grid Type (Text): Grid type: rectangular, offset_rectangular, hexagonal, triangular
  • Cell Width (Number): Cell width
  • Cell Height (Number): Cell height
  • Grout Width (Number): Width of the grout joint between tiles. Default 0.
  • Direction (Vector): Optional vector to align the grid's X-axis. Projects to the base plane.
  • Rotation (Number): Optional rotation angle (in degrees) applied after alignment.

Outputs (6)

  • Tile Status (Integer): 0 = full, 1 = trimmed
  • Full Count (Integer): Number of full tiles
  • Trimmed Count (Integer): Number of trimmed tiles
  • All Tiles (Curve): All grid tiles (trimmed and full)
  • Full Tiles (Curve): Tiles fully inside the boundary
  • Trimmed Tiles (Curve): Tiles partially inside the boundary
