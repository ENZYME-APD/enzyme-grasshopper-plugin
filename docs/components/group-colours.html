Group Colours

Changes the colors of groups on the canvas based on their names. Case-insensitive. Multi-separator.

Utilities Nickname: GroupColours

Overview

Changes the colors of groups on the canvas based on their names. Case-insensitive. Multi-separator.

Inputs (3)

  • Default Color (Colour): Default color for unmatched groups
  • Colors (Colour): List of colors corresponding to the names
  • Group Names (Text): List of group name prefixes

Outputs (0)

  • None

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. For every group on the canvas, the key is the group nickname in lower case, cut at the first -, _, : or | and trimmed.
  2. If the key equals a Group Names entry (case-insensitive), the group gets the colour with the same index (the last colour if the list is shorter); otherwise it gets Default Color.
  3. Fully transparent colours are replaced by grey (100, 100, 100) for matches and by 214, 206, 206 for the default.

Assumptions

  • Group nicknames start with one of the names, for example Analysis - Sun.

Simplifications and limits

  • Groups are recoloured only when the component solves, so new or renamed groups change colour at the next solve.
