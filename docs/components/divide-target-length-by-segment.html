Divide Target Length by Segment

Divides a curve by a target length, but respects kinks/discontinuities by dividing each structural segment independently.

Utilities Nickname: DivTrgtSeg

Overview

Divides a curve by a target length, but respects kinks/discontinuities by dividing each structural segment independently.

Inputs (2)

  • Curves (Curve): Curves to divide
  • Target Length (Number): Target length for subdivisions

Outputs (3)

  • Points (Point): Division points (without duplicates at kinks)
  • SubCurves (Curve): Divided sub-curves
  • Lengths (Number): Actual length of each sub-curve
