Facade Module: Frames

Facade frame on storey outlines: beams between each outline and its offset (BeamDepth), columns at equal bays, and optional sill, glass and header panels and vertical fins.

JSON Masterplan (Beta) Nickname: Mod_Frames

Overview

Deep structural exoskeleton grid utilizing the robust Area-Offset Method.

Inputs (14)

  • Bounds (Curve): Input bounds curves
  • Heights (Number): Input heights
  • BayWidth (Number): Width of each bay
  • BeamWidth (Number): Width of the beam
  • BeamDepth (Number): Depth of the beam
  • ColWidth (Number): Width of the column
  • ColDepth (Number): Depth of the column
  • HasPanel (Boolean): Enable inner facade panels
  • SillHeight (Number): Height of the sill
  • HeaderDrop (Number): Header drop distance
  • SubdivWidth (Number): Subdivision width
  • FinDepth (Number): Depth of the fins
  • FlipDir (Boolean): Flip direction
  • RemoveBaseBeam (Boolean): Remove base beam

Outputs (7)

  • Beams (Brep): Output beams
  • Columns (Brep): Output columns
  • Glass (Brep): Output glass panels
  • Fins (Brep): Output fins
  • HeaderPanels (Brep): Output header panels
  • SillPanels (Brep): Output sill panels
  • Info (Text): Method, assumptions, simplifications and references.

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. Each Bounds curve is one storey; all solids and surfaces are extruded upwards (world +Z), whatever the curve orientation. Its height comes from Heights at the same index in the same branch (default 4.0 if missing or 0.1 or less). Non-positive sizes fall back to the defaults.
  2. Offset side (area-offset method): a closed curve is offset by BeamDepth both ways and the larger result is taken as outside (inside if FlipDir). An open curve uses the positive offset side unless FlipDir.
  3. Beams: a closed solid between the curve and its offset, BeamWidth high, at the top of the storey (from h - BeamWidth to h). The lowest curve of each branch (by Z) also gets a base beam at the storey base unless RemoveBaseBeam.
  4. Columns: each segment is divided into round(length / BayWidth) equal bays; at every division point a ColWidth × ColDepth box, pointing towards the offset curve, rises the full storey height. Points repeated at the same position and tangent are placed once.
  5. With HasPanel, each bay gets surfaces on the boundary line: a sill of SillHeight, glass for the vision height, and a header of HeaderDrop below the top beam. Vision height = h - BeamWidth - sill - header (each clipped to fit).
  6. Fins: each bay with vision height is divided into round(bay length / SubdivWidth) parts; at the inner division points a vertical fin surface FinDepth deep, outward, covers the vision height.
  7. Status: glass area and solid (sill + header) area = bay length × height, plus column and fin counts.

Assumptions

  • Bounds are flat storey outlines at their floor level, in metres; Heights are floor-to-floor heights.
  • Bounds within a branch belong to one building.

Simplifications and limits

  • Glass, sill, header and fin elements are zero-thickness surfaces; only beams and columns are solids.
  • At corners two columns are placed, one per segment, because their tangents differ.
  • Columns run the full storey height and overlap the beams; the base beam overlaps the sill zone.
  • Bays are equal within each segment, so the actual bay width differs from BayWidth.

Workflow

  • Facade JSON Parser BoundsExt and Heights -> Bounds and Heights.
