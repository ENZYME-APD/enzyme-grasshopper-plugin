Branch-Concat

Concatenates items in each branch into a single string.

Data Nickname: Branch-Concat

Overview

Concatenates items in each branch into a single string.

Inputs (4)

  • tree (Generic): Tree to process
  • sep (Text): Separator between items
  • prefix (Text): Prefix for the joined string
  • suffix (Text): Suffix for the joined string

Outputs (1)

  • a (Text): Concatenated branches

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. For each branch of tree, converts every item to text (null items become None), joins them with sep and adds prefix and suffix; the result keeps the branch path.

Assumptions

  • Items have a meaningful text form (the Grasshopper ToString of the item).

Simplifications and limits

  • None beyond text conversion: numbers use the default Grasshopper formatting; empty branches give prefix + suffix.
