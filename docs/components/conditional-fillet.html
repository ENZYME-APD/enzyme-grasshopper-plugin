Conditional Fillet

Standard fillet components apply a single radius to an entire curve, which fails if any segment is too short. This "smart" solver evaluates and fillets a curve corner by corner.

Curve Nickname: CondFillet

Overview

Standard fillet components apply a single radius to an entire curve, which fails if any segment is too short. This "smart" solver evaluates and fillets a curve corner by corner.

Inputs (5)

  • curves (Curve): Input geometry (Polylines, Curves, Arcs)
  • radius (Number): The ideal fillet size you want.
  • threshold_pct (Number): Max % of a segment the fillet can consume.
  • skip (Boolean): True to skip tight corners; False to clamp.
  • round_dec (Integer): [Optional] Decimals to round down to.

Outputs (2)

  • out_curves (Curve): The final filleted geometry. (Preserves empty branches)
  • radii (Number): The exact radius applied to each specific corner.
