Sort Curves By Axis

Sorts a tree of curves based on their bounding box center along a specific axis.

Curve Nickname: SortAxis

Overview

Sorts a tree of curves based on their bounding box center along a specific axis.

Inputs (3)

  • Curves (Curve): Tree of curves to sort
  • Axis (Integer): Sort Axis (0=X, 1=Y, 2=Z)
  • Reverse (Boolean): Reverse sorting direction

Outputs (1)

  • Sorted Curves (Curve): Sorted tree of curves
