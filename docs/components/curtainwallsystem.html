CurtainWallSystem

Generates a detailed LOD 300 curtain wall system from base curves.

Facade Nickname: CWS

Overview

Generates a detailed LOD 300 curtain wall system from base curves.

Inputs (11)

  • BaseCurves (Curve): Planar boundary curves to extrude.
  • Heights (Number): Floor-to-floor heights corresponding to curves.
  • GridVertical (Number): Spacing pattern for vertical mullions (e.g., [1.5, 2.0]).
  • GridHorizontal (Number): Spacing pattern for horizontal transoms (e.g., [1.0, 2.0]).
  • Align (Text): Grid justification ('Start', 'Middle', 'End').
  • VertExt (Number): Fallback extrusion depth for vertical mullions.
  • HorExt (Number): Fallback extrusion depth for horizontal transoms.
  • DetailVertical (Curve): Optional 2D profile to sweep for vertical mullions.
  • DetailHorizontal (Curve): Optional 2D profile to sweep for horizontal transoms.
  • DetailCorner (Curve): Optional 2D profile to sweep for corner mullions.
  • CurvedGridVertical (Number): Optional alternative vertical spacing for curved segments.

Outputs (4)

  • Mullions (Brep): Generated vertical mullions.
  • Transoms (Brep): Generated horizontal transoms.
  • CornerMullions (Brep): Vertical mullions generated specifically at sharp vertices.
  • GlassWall (Brep): Uncapped extruded glass surfaces.
