CurtainWallSystem

Generates a detailed LOD 300 curtain wall system from base curves.

Facade Nickname: CWS

Overview

Generates a detailed LOD 300 curtain wall system from base curves.

Inputs (11)

  • BaseCurves (Curve): Planar boundary curves to extrude.
  • Heights (Number): Floor-to-floor heights corresponding to curves.
  • GridVertical (Number): Spacing pattern for vertical mullions (e.g., [1.5, 2.0]).
  • GridHorizontal (Number): Spacing pattern for horizontal transoms (e.g., [1.0, 2.0]).
  • Align (Text): Grid justification ('Start', 'Middle', 'End').
  • VertExt (Number): Fallback extrusion depth for vertical mullions.
  • HorExt (Number): Fallback extrusion depth for horizontal transoms.
  • DetailVertical (Curve): Optional 2D profile to sweep for vertical mullions.
  • DetailHorizontal (Curve): Optional 2D profile to sweep for horizontal transoms.
  • DetailCorner (Curve): Optional 2D profile to sweep for corner mullions.
  • CurvedGridVertical (Number): Optional alternative vertical spacing for curved segments.

Outputs (5)

  • Mullions (Brep): Generated vertical mullions.
  • Transoms (Brep): Generated horizontal transoms.
  • CornerMullions (Brep): Vertical mullions generated specifically at sharp vertices.
  • GlassWall (Brep): Uncapped extruded glass surfaces.
  • Info (Text): Method, assumptions, simplifications and references.

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. Each planar base curve is extruded straight up by its height to give one uncapped glass surface. Heights are matched to curves by branch path and by index; the last height repeats; 3.0 is used when no height is given.
  2. The curve is split into its segments. Along each segment the GridVertical pattern is repeated from the segment start (Align Start), centred (Middle) or pushed to the end (End); mullion positions strictly between the segment ends become vertical mullions. Curved segments use CurvedGridVertical instead, when given.
  3. Transom heights come from the GridHorizontal pattern repeated from the base (always Start alignment); heights at 0 or at the top are skipped. Each transom is a copy of the segment moved up to that height.
  4. Corner mullions are placed at every C2 discontinuity of the base curve, at its ends, and at extra points found per segment: every NURBS span end and every place where the sampled curvature (100 samples) changes by more than 10 % or switches between straight and curved.
  5. Each member is built from a closed profile curve when one is supplied (DetailVertical, DetailHorizontal, DetailCorner): the profile, drawn on world XY at the origin, is oriented to the rail start and swept along the rail (Sweep1). Otherwise the rail is extruded along the facade normal by VertExt (mullions and corners) or HorExt (transoms).
  6. The facade normal is tangent × world Z. Transoms use the average of 11 normals along the segment; corners use the average of the adjacent segment normals.

Assumptions

  • Base curves are planar and horizontal; extrusion is always along world Z.
  • Curve direction sets the normal: tangent × Z points to the right of the curve direction, which is outwards for a counter-clockwise closed curve.
  • Model units are metres (defaults 1.5 m grids, 3.0 m height, 0.5 m and 0.3 m fin depths).
  • Profile curves are closed and drawn on world XY around the origin.

Simplifications and limits

  • Without profiles, mullions and transoms are single zero-thickness surfaces (fins), not solids.
  • Glass is one surface per base curve, not split into panels by the grid, and has no thickness.
  • Transom ribbons on curved segments are extruded along one averaged normal, so their depth varies along the curve.
  • Mullions at segment ends are not generated by the grid; those positions rely on the corner mullions.

Workflow

  • Floor outlines and floor-to-floor heights (for example from a massing tool) -> BaseCurves and Heights.
  • CWProfile -> DetailVertical, DetailHorizontal, DetailCorner for detailed sections.
