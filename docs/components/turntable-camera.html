Turntable Camera

Automated camera rotation and sequence rendering for 360° product/site views.

Utilities Nickname: Turntable

Overview

Automated camera rotation and sequence rendering for 360° product/site views.

Inputs (12)

  • Target (Point): Focal point for camera center axis
  • Radius (Number): Orbital distance to camera location
  • Elevation (Number): Z-axis elevation offset of camera relative to target
  • Frames (Integer): Number of frame captures per 360 loop
  • Directory (Text): Output directory where images are saved
  • Prefix (Text): Prefix for the image files
  • Width (Integer): Export width in pixels
  • Height (Integer): Export height in pixels
  • DPI (Integer): Print resolution in Dots Per Inch
  • Transparent (Boolean): Export with a transparent background
  • Scale Items (Boolean): Scale lineweights and screen items
  • Run (Boolean): Trigger the export loop

Outputs (5)

  • Orbit Path (Curve): The circular path of the camera.
  • Camera Points (Point): Calculated 3D camera coordinates.
  • Target Out (Point): Passthrough of the focal target point.
  • File Paths (Text): Paths of exported PNG frames.
  • Info (Text): Component execution HUD.
