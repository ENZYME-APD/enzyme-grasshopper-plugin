Noise Emitter From Curves

Converts line/curve paths (like roads or railways) into discrete noise emitter points with associated dB values.

Site Analysis Nickname: NoiseLines

Overview

Converts line/curve paths (like roads or railways) into discrete noise emitter points with associated dB values.

Inputs (3)

  • Curve Paths (Curve): Lines/Curves representing noise sources (e.g. roads, railways)
  • Average Noises (Number): Average noise levels matching the roads (dB). Re-uses last value if list is shorter.
  • Divide Length (Number): Distance (m) between emitter points along the curve

Outputs (2)

  • Points (Point): Generated discrete noise emitter points
  • Noise Values (Number): Decibel values mapped exactly to the points
