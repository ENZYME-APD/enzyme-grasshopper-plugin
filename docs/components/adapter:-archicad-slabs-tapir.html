Overview

Adapter for Archicad Slabs using Tapir workflow

Inputs (6)

  • FloorContours (Curve): List of floor contours
  • FloorHeights (Number): List of floor heights
  • SnapTolerance (Number): Tolerance for healing floor heights
  • Programs (Text): List of program names
  • TowerIDs (Text): List of tower IDs
  • BuildingNames (Text): List of building names

Outputs (2)

  • JSON_Payload (Text): Output JSON payload
  • Info (Text): Method, assumptions, simplifications and references.

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. All input trees are flattened and matched by index: floor contour i takes FloorHeights i, Programs i, TowerIDs i and BuildingNames i. Missing names default to Mixed_Use, Main_Mass and Building_01. Null items in FloorContours or FloorHeights keep their index: that floor is skipped and later floors keep their own heights.
  2. Each floor's base level is the lowest Z of its contour's bounding box; its top is base + FloorHeights.
  3. Floors are grouped by BuildingNames, then by TowerIDs, and sorted by base level within each tower.
  4. Healing: if the gap between a floor's base and the top of the floor below in the same tower is between 0.001 and SnapTolerance (default 0.15, either above or below), the base is snapped to that top. The top stays where it was, so the floor height grows or shrinks by the gap.
  5. Each building's true_base_elevation is its lowest healed base; every floor is written as a one-floor block with base_z relative to it (rounded to 0.001) and floor_height = healed height.
  6. Outlines are written as Polyline points if the curve is a polyline; otherwise the curve is converted to arcs and lines (tolerance 0.05, angle 0.1 rad) and each segment is written as Line, Arc (start, mid, end) or a Polyline approximation (tolerance 0.01). Coordinates are rounded to 4 decimals.

Assumptions

  • Contours are flat, closed slab outlines in model units (metres), one per floor.
  • The flattened lists of contours, heights and names are in the same order.
  • Floors of one tower stack vertically; small gaps or overlaps up to SnapTolerance are modelling errors, not design intent.

Simplifications and limits

  • Data tree structure is ignored: everything is matched by flat index.
  • Every floor becomes its own block (floors = 1); repeated floors are not merged.
  • Free-form curves are approximated by arcs, lines and polylines.
  • Block names use the relative level rounded to whole units, so they can repeat; they are labels only.

Workflow

  • Archicad slab outlines and heights (through Tapir) -> FloorContours and FloorHeights. JSON_Payload -> JSON_Payload of JSON MP Engine V2.
