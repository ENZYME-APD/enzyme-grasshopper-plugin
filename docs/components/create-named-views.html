Create Named Views

Converts a list of camera locations and targets into Rhino Named Views. Combine with Advanced Export Views for flythroughs and animations.

Utilities Nickname: NamedViews

Overview

Converts a list of camera locations and targets into Rhino Named Views. Combine with Advanced Export Views for flythroughs and animations.

Inputs (5)

  • Locations (Point): List of 3D points for the camera positions.
  • Targets (Point): List of 3D points for the camera targets. If only one is provided, the camera will always look at it.
  • Lens Length (Number): Camera lens length in mm (e.g. 50).
  • Prefix (Text): Prefix for the generated Named Views.
  • Run (Boolean): Trigger to generate the views in the Rhino document.

Outputs (2)

  • View Names (Text): List of generated Named View names (Plug this into Advanced Export Views!)
  • Info (Text): Component execution HUD.
