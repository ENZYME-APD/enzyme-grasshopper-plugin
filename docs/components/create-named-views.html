Create Named Views

Converts a list of camera locations and targets into Rhino Named Views. Combine with Advanced Export Views for flythroughs and animations.

Utilities Nickname: NamedViews

Overview

Converts a list of camera locations and targets into Rhino Named Views. Combine with Advanced Export Views for flythroughs and animations.

Inputs (5)

  • Locations (Point): List of 3D points for the camera positions.
  • Targets (Point): List of 3D points for the camera targets. If only one is provided, the camera will always look at it.
  • Lens Length (Number): Camera lens length in mm (e.g. 50).
  • Prefix (Text): Prefix for the generated Named Views.
  • Run (Boolean): Trigger to generate the views in the Rhino document.

Outputs (2)

  • View Names (Text): List of generated Named View names (Plug this into Advanced Export Views!)
  • Info (Text): Component execution HUD.

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. When Run is True, for each Locations point it places the active viewport camera there, aims it at the matching Targets point (one target for all, or targets cycled by index) and sets the 35 mm lens length (default 50 mm).
  2. Each camera is saved as a Rhino Named View called Prefix + a 4-digit index (Shot_0000, Shot_0001...); an existing view with the same name is replaced. The original viewport camera is restored afterwards.

Assumptions

  • Views are saved from the active viewport, so its projection (perspective) and size are used.
  • When camera and target coincide, the camera looks along +Y.

Simplifications and limits

  • View Names is only filled while Run is True; it is empty otherwise.
  • Named view changes are not added to Rhino's undo.

Workflow

  • Camera path points (e.g. Divide Curve) -> Locations; a focus point -> Targets.
  • View Names -> Views of Advanced Export Views.
