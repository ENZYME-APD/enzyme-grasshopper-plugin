Site Analysis Nickname: AnaDash

Overview

Reads a JSON payload from Terrain/LEAP analysis tools and renders a responsive Legend HUD.

Inputs (10)

  • Run (Boolean): Enable HUD
  • Dashboard Data (Text): JSON string representing the analysis data or legend
  • Size (Number): Base text size
  • Anchor (Integer): 0=TL, 1=TR, 2=BL, 3=BR
  • Font (Text): Font family name
  • Font Color (Colour): Text color
  • Transparency (Number): HUD background opacity (0-1)
  • Offset X (Number): X margin from screen edge
  • Offset Y (Number): Y margin from screen edge
  • Padding (Number): Padding inside the HUD box

Outputs (0)

  • None
