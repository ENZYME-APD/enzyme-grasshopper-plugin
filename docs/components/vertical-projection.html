Vertical Projection

Projects a point vertically (along world Z-axis) onto a given plane.

Facade Nickname: VertProj

Overview

Projects a point vertically (along world Z-axis) onto a given plane.

Inputs (2)

  • Point (Point): Input point
  • Plane (Plane): Input plane

Outputs (3)

  • Is Contained (Boolean): Boolean if the point is on the plane
  • Projected Point (Point): The actual projected Point3d
  • Message (Text): Multi-line message output

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. Intersects a vertical line through Point (±10,000 units along world Z) with Plane and returns that point; Is Contained is True when the point is within 1e-6 of the plane.

Assumptions

  • The plane is not vertical; for a vertical plane there is no intersection and the original point is returned.

Simplifications and limits

  • None beyond a single line-plane intersection.
