Vertical Projection

Projects a point vertically (along world Z-axis) onto a given plane.

Pattern Nickname: VertProj

Overview

Projects a point vertically (along world Z-axis) onto a given plane.

Inputs (2)

  • Point (Point): Input point
  • Plane (Plane): Input plane

Outputs (3)

  • Is Contained (Boolean): Boolean if the point is on the plane
  • Projected Point (Point): The actual projected Point3d
  • Message (Text): Multi-line message output
