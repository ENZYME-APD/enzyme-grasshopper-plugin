Save Named View

Saves the current active Rhino viewport as a Named View.

Utilities Nickname: SaveView

Overview

Saves the current active Rhino viewport as a Named View.

Inputs (3)

  • Name (Text): Name for the saved view
  • Save (Boolean): Button to trigger saving
  • Overwrite (Boolean): Overwrite if a view with the same name exists

Outputs (2)

  • Available Views (Text): List of all named views currently saved in the Rhino document
  • Info (Text): Component information and methodology

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. When Save is True and Name is not empty, the active viewport of the active Rhino document is saved as a Named View. If the name exists it is deleted and re-added when Overwrite is True, otherwise skipped with a warning.
  2. Available Views lists all named views in the document.

Assumptions

  • Save is a button; a toggle left True saves again on every solution.

Simplifications and limits

  • None beyond saving the active viewport's camera as Rhino does.

Workflow

  • Save Named View, then Document Size to Pixels -> Export Named Views.
