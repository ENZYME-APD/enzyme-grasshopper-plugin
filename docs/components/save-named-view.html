Save Named View

Saves the current active Rhino viewport as a Named View.

Utilities Nickname: SaveView

Overview

Saves the current active Rhino viewport as a Named View.

Inputs (3)

  • Name (Text): Name for the saved view
  • Save (Boolean): Button to trigger saving
  • Overwrite (Boolean): Overwrite if a view with the same name exists

Outputs (2)

  • Available Views (Text): List of all named views currently saved in the Rhino document
  • Info (Text): Component information and methodology
