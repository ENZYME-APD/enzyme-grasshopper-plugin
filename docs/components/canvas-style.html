Canvas Style

Modifies the global canvas background, grid, and panel default colors. The change applies to the whole Grasshopper application and stays after this component or file is closed; to go back, set the colours you want again (the previous colours are not restored).

Utilities Nickname: CanvasStyle

Overview

Modifies the global canvas background, grid, and panel default colors.

Inputs (3)

  • Panel Default Color (Colour): Default color for panels
  • Canvas Background Color (Colour): Background color for the canvas
  • Canvas Gridline Color (Colour): Color for the canvas gridlines

Outputs (0)

  • None

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. Sets the global Grasshopper skin colours for panel background, canvas background and canvas grid from the three colour inputs and refreshes the canvas.

Assumptions

  • The colours apply to the whole Grasshopper application, not only this document.

Simplifications and limits

  • None beyond setting three skin colours; nothing is restored when the component is deleted.
