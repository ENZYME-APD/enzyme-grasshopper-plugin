Auto-Grade Road

Procedurally drapes and slope-constrains a 2D centerline into a smooth 3D road profile.

Masterplan Nickname: AutoGrade

Overview

Procedurally drapes and slope-constrains a 2D centerline into a smooth 3D road profile.

Inputs (5)

  • Centerline (Curve): Flat 2D Centerline
  • Terrain (Mesh): Existing Ground Mesh
  • Max Slope (Number): Maximum longitudinal slope (e.g. 0.08 for 8%)
  • Resolution (Number): Subdivision distance in meters
  • Smoothing (Integer): Smoothing iterations for vertical curvature

Outputs (2)

  • 3D Road (Curve): The optimized, slope-constrained 3D centerline
  • Existing Ground (Curve): The raw draped profile on the terrain
