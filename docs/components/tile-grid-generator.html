Grid Pattern Generator and Trimmer GridPattern

Generates a grid pattern (rectangular, offset rectangular, hexagonal, triangular) within a boundary curve and trims cells to fit.

Inputs

Name Nickname Type Access Default Description
Boundary Boundary Curve Item — Closed boundary curve
Origin Plane Plane Plane Item WorldXY Grid base plane
Grid Type Grid Type Text Item "rectangular" Grid type: rectangular, offset_rectangular, hexagonal, triangular
Cell Width X Dim Number Item 1.0 Cell width
Cell Height Y Dim Number Item 1.0 Cell height (used for rectangular types)

Outputs

Name Nickname Type Access Description
Tile Status Tile Status Integer List 0 = full tile, 1 = trimmed tile
Full Count Full Count Integer Item Number of full tiles
Trimmed Count Trim Count Integer Item Number of trimmed tiles
All Tiles All Tiles Curve List All grid tiles (both full and trimmed)
Full Tiles Full Tiles Curve List Tiles fully inside the boundary
Trimmed Tiles Trimmed Tiles Curve List Tiles partially inside the boundary, clipped

Notes & Behaviour

Uses local plane coordinate space for all grid calculations then transforms back to world space. Supports 4 grid types. Status message shows grid type, full/trimmed counts, and execution time.
