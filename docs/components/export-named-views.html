Export Named Views

Exports Rhino Named Views to image files with custom ViewCapture settings.

Utilities Nickname: ExportViews

Overview

Exports Rhino Named Views to image files with custom ViewCapture settings.

Inputs (15)

  • Run (Boolean): Set to true to export the views.
  • Views (Text): Names of the views to export. If empty, exports ALL named views.
  • Display Style (Text): Optional. Name of the Display Mode (e.g., 'Rendered'). Leaves active if empty.
  • Layer State (Text): Optional. Name of the saved Layer State to restore. Leaves active if empty.
  • Directory (Text): Folder path to save the images.
  • Prefix (Text): Prefix for the output filenames (optional).
  • Suffix (Text): Suffix for the output filenames (optional).
  • Format (Text): Image format: png, jpg, bmp, tiff.
  • Width (Integer): Image width in pixels.
  • Height (Integer): Image height in pixels.
  • DPI (Integer): Print DPI metadata embedded into the image.
  • Grid (Boolean): Show Grid.
  • World Axes (Boolean): Show World Axes.
  • CPlane Axes (Boolean): Show CPlane Axes.
  • Transparent (Boolean): Transparent background (PNG only).

Outputs (2)

  • Saved Files (Text): Paths to the saved image files.
  • Info (Text): Component information and interpretation
