Site Analysis Nickname: Heatmap

Overview

Colours any analysis mesh from its values: flat cells, smooth gradient, contour bands with labelled isolines, or comfort classes (UTCI, Lawson, noise). Also reports the % of area in each band.

Inputs (15)

  • Mesh (Mesh): Analysis mesh, e.g. Fast CFD WindMesh (with its VertexSpeeds as Values and BuildingMask as Mask), Sun Hours or Noise mesh
  • Values (Number): One value per mesh vertex or per mesh face (detected automatically)
  • Mode (Text): Cells, Smooth, Contour or Classes (0-3 also accepted)
  • Levels (Integer): Contour: number of bands (rounded to nice steps when Min/Max are not set)
  • Smooth (Integer): Smoothing passes on the values (0 = none, 1-3 light, 5-10 strong). Masked cells are left out
  • Min (Number): Colour range minimum (default: data minimum). Set the same Min/Max on every option to compare them fairly
  • Max (Number): Colour range maximum (default: data maximum)
  • Palette (Text): Palette name (Viridis, Cividis, Turbo, Ladybug, Thermal, Wind, RdBu...). Add ' r' / '_r' to reverse
  • Colors (Colour): Custom gradient (overrides Palette)
  • Mask (Boolean): Optional: one bool per face, True = building / no data (kept grey, excluded from smoothing, contours and stats)
  • Scheme (Text): Classes mode: UTCI (°C), Lawson (m/s), Noise (dB), Slope (%: 0-5, 5-15, 15-30, >30) or Flood depth (m: 0.1, 0.3, 0.5)
  • Title (Text): Legend title, e.g. 'Wind speed (m/s)'
  • LabelSpacing (Number): Distance between isoline labels (0 = no labels, default: 15% of the map size)
  • LabelSize (Number): Label text height (default: 1.2% of the map size)
  • Peaks (Integer): Number of high-point labels (0 = none). Negative = label low points instead

Outputs (10)

  • Heatmap (Mesh): Coloured mesh
  • Isolines (Curve): Contour lines (Contour / Classes modes)
  • IsoValues (Number): Value of each isoline
  • LabelPlanes (Plane): Isoline + peak label planes, aligned with the line and always readable (feed Text Tag 3D)
  • LabelText (Text): Label strings
  • LabelSize (Number): Text height used for the labels
  • BandStats (Text): % of the (unmasked) area in each band / class, for report tables
  • BandAreas (Number): Area of each band / class (model units²)
  • Dashboard Data (Text): JSON legend payload for Legend Geometry / Analysis Dashboard
  • Info (Text): Component information and interpretation
