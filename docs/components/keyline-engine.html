Keyline Engine

Generates parametric plowing lines or swale networks by offsetting guide curves along a terrain mesh.

Site Analysis Nickname: Keyline

Overview

Generates parametric plowing lines or swale networks by offsetting guide curves along a terrain mesh.

Inputs (5)

  • Terrain (Mesh): The base topography mesh
  • Guide Curves (Curve): The reference contours or keylines
  • Spacing (Number): Horizontal distance between plowing lines
  • Count (Integer): Number of parallel lines to generate per side
  • Run (Boolean): Optional. False = skip the analysis and keep showing the last results (cached). Share one toggle with the Analysis Dashboard to switch everything on/off together.

Outputs (3)

  • Keylines (Curve): Generated 3D swale/plow curves projected on terrain
  • Info (Text): Component information and methodology
  • Dashboard Data (Text): Unified JSON payload containing legend and key analysis metrics for the Analysis Dashboard

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. Each Guide Curve is projected vertically onto Terrain and output.
  2. For i = 1 to Count, the guide is offset in the World XY plane by ± Spacing × i (sharp corners, tolerance 0.01) and each offset is projected vertically (along Z) onto Terrain.
  3. All projected curves form Keylines; the HUD and Dashboard Data report the number of curves and their total 3D length.

Assumptions

  • Guide Curves are planar in plan (for example contours or a drawn keyline); offsets are computed in World XY.
  • Spacing is a horizontal distance in model units (metres assumed in the dashboard text).

Simplifications and limits

  • Lines are equal plan offsets of the guide, not true keyline geometry: no fall or grade is computed or controlled along each line, and they do not follow the contours.
  • Offsets that self-intersect on tight curves are kept as returned by Rhino; offsets that fall off the terrain are dropped.

Workflow

  • Terrain mesh -> Terrain; a contour or keyline through the keypoint (for example from a contour component) -> Guide Curves.
  • Keylines -> drawings or swale layout; Dashboard Data -> Analysis Dashboard.

References

  • Yeomans P.A. (1958), The Challenge of Landscape: the keyline system.
