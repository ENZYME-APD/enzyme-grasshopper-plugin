Higrothermal Comfort

Maps wind-engine velocity samples onto apparent ("feels like") temperature and locates the best/worst comfort points, without requiring a regular grid.

Site Analysis Nickname: HigroComfort

Overview

Maps wind-engine velocity samples onto apparent ("feels like") temperature and locates the best/worst comfort points, without requiring a regular grid.

Inputs (9)

  • Run (Boolean): Global execution toggle switch
  • TerrainMesh (Mesh): The underlying site topography - its own vertices/connectivity are reused directly for ComfortMesh, no separate grid is built
  • VelocityValues (Number): Raw wind speeds (m/s), aligned index-for-index with TagPoints - e.g. from the wind engine's VelocityValues output
  • TagPoints (Point): Sample points matching VelocityValues index-for-index - e.g. from the wind engine's TagPoints output
  • Humidity (Number): Relative humidity (%), currently a single constant across the whole site
  • Temperature (Number): Ambient dry-bulb air temperature (deg C), currently a single constant across the whole site
  • IdealTemperature (Number): The apparent temperature (deg C) considered ideal/neutral comfort - deviation from this defines best/worst
  • ComfortTolerance (Number): Fraction (0-1) of the observed deviation-from-ideal range within which a point still counts as Best (near the minimum) or Worst (near the maximum)
  • CustomColors (Colour): Custom color spectrum override for the comfort mesh

Outputs (10)

  • BestComfortPoints (Point): Point(s) with apparent temperature closest to IdealTemperature, within ComfortTolerance of the single best
  • BestComfortValues (Number): The apparent temperatures for the BestComfortPoints
  • WorstComfortPoints (Point): Point(s) with apparent temperature furthest from IdealTemperature, within ComfortTolerance of the single worst
  • WorstComfortValues (Number): The apparent temperatures for the WorstComfortPoints
  • ComfortMesh (Mesh): The input terrain mesh, vertex-colored by comfort deviation
  • TagPoints (Point): Pass-through of the input tag points
  • ComfortValues (Number): Raw apparent temperature (deg C) per terrain vertex
  • ComfortColors (Colour): List of colors corresponding to each vertex on the mesh
  • Info (Text): Component information and interpretation
  • Dashboard Data (Text): Unified JSON payload containing legend and key analysis metrics for the Analysis Dashboard
