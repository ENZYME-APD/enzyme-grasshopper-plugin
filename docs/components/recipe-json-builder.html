Recipe JSON Builder

Parametrically compiles lists of programs, heights, and floor counts into the standardized JSON array required by the Stage 1 Adapters.

JSON Masterplan (Beta) Nickname: RecipeBuilder

Overview

Parametrically compiles lists of programs, heights, and floor counts into the standardized JSON array required by the Stage 1 Adapters.

Inputs (3)

  • Program (Text): Program (e.g., Retail, Office, Hotel)
  • FloorHeight (Number): Floor height (e.g., 4.5, 4.0, 3.3)
  • NumFloors (Integer): Number of floors (e.g., 3, 10, 5)

Outputs (1)

  • RecipeJSON (Text): The formatted JSON payload.

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. Matches Program, FloorHeight and NumFloors by index (up to the shortest list) and writes a JSON array of objects with program, height (floor-to-floor) and floors.
  2. The status shows the number of blocks, total floors and total height = sum of floors × height.

Assumptions

  • Heights are floor-to-floor heights in metres; the list order is the stacking order from the bottom.

Simplifications and limits

  • Extra items in longer lists are ignored without a warning.

Workflow

  • Recipe JSON Builder -> RecipeJSON of Adapter: The Sculptor (AD_SCULPT).
