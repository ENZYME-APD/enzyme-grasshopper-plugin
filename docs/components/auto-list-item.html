Auto List Item

Extracts an item from a list. Can automatically wire and adjust a slider to match the list's length.

Data Nickname: AutoItem

Overview

Extracts an item from a list. Can automatically wire and adjust a slider to match the list's length.

Inputs (2)

  • List (Generic): List to extract item from
  • Index (Integer): Index of the item to retrieve

Outputs (1)

  • Item (Generic): Extracted item

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. Returns the item of List at Index. With Wrap Indices on (default, right-click menu) the index wraps around with a modulo, so negative and too-large values cycle; with it off the index is clamped to the first or last item.
  2. If a Number Slider feeds Index, its maximum is reset to the list length minus 1 on the next solution (and its value clamped). Auto-wire Index Slider adds an integer slider 0 to 10 when Index is empty.

Assumptions

  • List is a flat list per solution; on data trees the component runs once per branch like any list-access component.

Simplifications and limits

  • None beyond the wrap or clamp rule; an empty List gives no output.
