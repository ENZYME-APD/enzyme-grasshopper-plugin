Data Visualizer

Visualizes points and data values as a fast gradient mesh (Bars, Dots, or Spheres).

Utilities Nickname: DataVis

Overview

Visualizes points and data values as a fast gradient mesh (Bars, Dots, or Spheres).

Inputs (6)

  • Points (Point): List of 3D Points
  • Values (Number): List of data values matching the points
  • Colors (Colour): Gradient color palette
  • Domain (Interval): Target domain for geometry size (Radius/Height)
  • Type (Integer): Visual Type (0: Bar, 1: Flat Dot, 2: Sphere)
  • Bar Thickness (Number): Thickness for Bar Chart (Type 0 only)

Outputs (4)

  • Visualization (Mesh): A single joined mesh representing the data (for fast viewport rendering)
  • Values (Number): The data values corresponding to the points
  • Colors (Colour): The interpolated colors corresponding to the points
  • Info (Text): Component information and interpretation

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. Values are normalised with the minimum and maximum of the Values list: t = (v - min) / (max - min); if all values are equal the range is set to 1.
  2. Size = Domain start + t × Domain length; colour = linear RGB interpolation between Colors spaced evenly over t (white if no colours).
  3. Type 0 draws a hexagonal prism of height Size and circumradius Bar Thickness (cycled per point), standing upright in world Z. Type 1 draws a flat hexagon of radius Size in a world XY plane. Type 2 (and any other value) draws an icosahedron of circumradius Size.
  4. All shapes are joined into one vertex-coloured mesh; Values and the interpolated Colors are also output per point.

Assumptions

  • Points and Values are in the same order; extra points or values are ignored.

Simplifications and limits

  • Spheres are 20-face icosahedra and bars are hexagonal prisms, for speed.
  • Shapes are aligned to world axes, not to any surface; mesh normals are not computed.

Workflow

  • Any analysis that outputs points and values -> Points and Values.
