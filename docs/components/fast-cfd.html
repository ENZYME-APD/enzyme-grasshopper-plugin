Fast CFD

A 2.5D Terrain-Following Grid Fluid Solver for fast urban wind analysis.

Site Analysis Nickname: FastCFD

Overview

A 2.5D Terrain-Following Grid Fluid Solver for fast urban wind analysis.

Inputs (12)

  • TerrainMesh (Mesh): Input Terrain Mesh
  • ContextMeshes (Mesh): Buildings and context as closed meshes
  • WindVector (Vector): Wind direction
  • WindSpeed (Number): Baseline wind velocity (m/s)
  • CellSize (Number): Resolution of the grid in meters.
  • Iterations (Integer): Simulation steps
  • AnalysisHeight (Number): Drape offset above terrain (m)
  • Viscosity (Number): Kinematic viscosity (diffusion/turbulence)
  • Friction (Number): Surface drag (0.0 to 1.0). Accepts item or list.
  • ComfortThreshold (Number): Threshold for pedestrian comfort (m/s)
  • BoundaryMask (Curve): Optional closed curve to crop the simulation domain and filter statistics.
  • Colors (Colour): Custom color spectrum override (min to max)

Outputs (7)

  • WindMesh (Mesh): Heatmap of wind speeds mapped to the terrain
  • Points (Point): Grid points corresponding to the vectors
  • WindVectors (Vector): Wind velocity vectors for visualization
  • Colors (Colour): The color assigned to each point/vector
  • Speeds (Number): Wind speed magnitude (m/s) at each point
  • Dashboard Data (Text): JSON string for Dashboard and Legend
  • Info (Text): Simulation data and timing
