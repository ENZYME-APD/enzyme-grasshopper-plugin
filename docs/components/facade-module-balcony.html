Facade Module: Balcony

Continuous balconies with 2D wall patterns and intelligent corners.

Masterplan Nickname: Mod_Balcony

Overview

Continuous balconies with 2D wall patterns and intelligent corners.

Inputs (15)

  • Bounds (Curve): Boundary curves
  • Heights (Number): Floor heights
  • BayWidth (Number): Width of each bay
  • Depth (Number): Depth of the balcony
  • RailHeight (Number): Height of the railing
  • SillHeight (Number): Height of the sill
  • HeaderDrop (Number): Header drop distance
  • HorizPattern (Text): Horizontal pattern array
  • VertPattern (Text): Vertical pattern
  • BalconyPattern (Text): Balcony pattern
  • FlipDir (Boolean): Flip direction
  • FirstBalcony (Boolean): Toggle first balcony
  • CornerWindow (Boolean): Toggle corner window
  • CornerOffset (Number): Corner offset distance
  • SegLength (Boolean): Segment length bypass

Outputs (6)

  • Slabs (Brep): Slab Breps
  • Railings (Brep): Railing Breps
  • Glass (Brep): Vision glass Breps
  • SolidPanels (Brep): Solid wall Breps
  • HeaderPanels (Brep): Header drop Breps
  • CornerPanels (Brep): Corner window Breps
