Procedural Road Generator

Generates procedural roads, bridges, and terrain cuts/fills using a blazing fast 2.5D approach.

Masterplan Nickname: RoadGen

Overview

Generates procedural roads, bridges, and terrain cuts/fills using a blazing fast 2.5D approach.

Inputs (11)

  • Centerlines (Curve): List of 3D road centerlines
  • Terrain (Mesh): Base landscape mesh
  • Directions (Integer): Number of directions (1 or 2)
  • Lanes/Dir (Integer): Number of lanes per direction
  • Lane Width (Number): Width of an individual lane
  • Shoulder (Number): Width of the hard shoulder
  • Threshold (Number): Max vertical distance before becoming a bridge
  • Pillar Sep (Number): Distance between bridge pillars
  • Blend Angle (Number): Embankment cut/fill slope angle (degrees)
  • Subdivide (Number): Resolution along the road for terrain modification
  • Colorize (Boolean): Colorize terrain/volumes for Cut (Red) and Fill (Blue)

Outputs (9)

  • Terrain (Mesh): Modified terrain mesh
  • Road Table (Mesh): Asphalt surface mesh
  • Lanes (Curve): Lane centerlines
  • Railings (Curve): Road boundaries and shoulders
  • Pillars (Curve): Bridge pillar lines
  • Cut Volume (Mesh): Excavated earth volume
  • Fill Volume (Mesh): Added earth volume
  • Contours (Curve): Normal contours (1m)
  • Main Contours (Curve): Main contours (5m)
