Masterplan Nickname: RoadGen

Overview

Procedurally generates a full road corridor (asphalt mesh, lanes, railings, bridge pillars) by projecting a centerline onto a terrain mesh. Includes accurate quad-splitting cut/fill volumetric solids.

Inputs (4)

  • Terrain (Mesh): Base topography mesh
  • Network (Curve): Centerline curve(s) of the road
  • Parameters (Text): Road parameters JSON from Spec Component
  • Exclusions (Point): Points to exclude from generation

Outputs (9)

  • Terrain (Mesh): Modified terrain mesh
  • Road Table (Mesh): Asphalt surface mesh
  • Lanes (Curve): Lane centerlines
  • Railings (Curve): Road boundaries and shoulders
  • Pillars (Curve): Bridge pillar lines
  • Cut Volume (Mesh): Excavated earth volume
  • Fill Volume (Mesh): Added earth volume
  • Contours (Curve): Normal contours (1m)
  • Main Contours (Curve): Main contours (5m)
