Site Analysis Nickname: SunHours

Overview

Multi-threaded raycaster. Analyzes arbitrary 3D massing or custom points for sun exposure.

Inputs (8)

  • Test Points (Point): (Workflow 2) High LOD: Specific points to test (e.g., window centroids). Overrides Massing.
  • Geometry (Geometry): (Workflow 1) Low LOD: 3D Massing (Breps) or Terrain (Meshes) to analyze.
  • Grid Size (Number): Subdivision size for auto-meshing the Massing.
  • Context (Mesh): Environment geometry (buildings, terrain) as shadow casters.
  • Sun Vectors (Vector): Solar vectors from the Heliodon.
  • Gradient (Colour): Optional custom color gradient (list of colors from 0% to 100%).
  • Run (Boolean): Trigger the analysis.
  • Offset (Number): Offset distance for output points.

Outputs (7)

  • Sun Hours (Integer): Total number of sun rays that reached the point.
  • Exposure % (Number): Percentage of time in the sun (0.0 to 1.0).
  • Points Out (Point): The analyzed points.
  • Analysis Mesh (Mesh): The auto-subdivided Massing mesh (for easy gradient coloring).
  • Colors (Colour): Color mapped to each point.
  • Dashboard Data (Text): JSON legend data
  • Colors (Colour): Color mapped to each point based on exposure.
