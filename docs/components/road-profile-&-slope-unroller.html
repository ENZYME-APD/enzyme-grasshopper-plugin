Road Profile & Slope Unroller

Unrolls a 3D road centerline into a 2D profile graph (elevation vs. distance) alongside its segmented slope analysis.

Masterplan Nickname: ProfileUnroll

Overview

Unrolls a 3D road centerline into a 2D profile graph (elevation vs. distance) alongside its segmented slope analysis.

Inputs (7)

  • Curves (Curve): 3D curves representing road centerlines
  • Threshold (Number): Slope threshold
  • Segment Size (Number): Size of segments for analysis
  • Threshold Mode (Integer): 0: Degrees, 1: Percentage, 2: Ratio 1:X
  • Z Exaggeration (Number): Vertical scale multiplier for the profile graph
  • Reference Y (Number): Base elevation (Y-coordinate) to drop alignment lines down to
  • Base Plane (Plane): Origin plane for the unrolled profile graph

Outputs (11)

  • Profile Curves (Curve): Continuous unrolled 2D profile curve
  • Analyzed Segments (Curve): 2D lines representing the slope segments
  • Slope Values (Number): Slope values for each segment
  • Center Points 2D (Point): 2D center points for tagging
  • Segment Status (Text): Status (Compliant / Non-Compliant)
  • Compliance Percentage (Number): Overall compliance percentage
  • Dashboard Data (Text): JSON legend data
  • Alignment Lines (Curve): Vertical lines dropping from breakpoints to Ref Y
  • Alignment Labels (Text): Structural geometry labels (Line, Arc, Spline)
  • Alignment Points (Point): Placement points for alignment labels
  • Info (Text): Method, assumptions, simplifications and references.

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. Profile: each curve is sampled at 201 points; each point is plotted on Base Plane at x = 3D length along the curve from its start and y = Z × Z Exaggeration, and a degree-3 interpolated curve is fitted through them.
  2. Analysis: the curve is cut into N = ceil(length / Segment Size) equal-length pieces. Slope per segment uses the straight chord between the segment end points: horizontal distance H in plan and absolute height change V; degrees = atan(V / H), percent = V / H × 100, ratio = H / V (1:X).
  3. A segment is Compliant if slope ≤ Threshold (degrees or percent) or ratio ≥ Threshold (ratio mode, flat segments always compliant). Compliance % is the share of compliant segments over all curves.
  4. Segments, centre points and status are drawn on the same profile graph.
  5. Alignment: the curve is split into its own segments (polyline spans, arcs, splines); a vertical line drops from each break point to Ref Y, and each span is labelled Line L, Arc R or Spline L (rounded to 0.1) at Ref Y − 2 × Z Exaggeration.

Assumptions

  • Curves are 3D road centrelines drawn in the direction of chainage, in metres.
  • Ref Y is in graph units, i.e. already scaled (an elevation × Z Exaggeration).
  • Threshold is in the units chosen by Mode (default 8 %).

Simplifications and limits

  • The horizontal axis is 3D length along the curve, not plan chainage, so steep roads plot slightly longer than their plan length.
  • Slope is an average over each segment; peaks shorter than Segment Size are smoothed out. Uphill and downhill are not distinguished.
  • Elevations are plotted as absolute Z (no datum subtraction), so Base Plane origin must be set accordingly.

Workflow

  • 3D road centrelines (for example from Road Corridor or a graded alignment) -> Curves.
  • Segments and Status -> colour by status for long sections; Dashboard Data -> legend.
