Road Profile & Slope Unroller

Unrolls a 3D road centerline into a 2D profile graph (elevation vs. distance) alongside its segmented slope analysis.

Masterplan Nickname: ProfileUnroll

Overview

Unrolls a 3D road centerline into a 2D profile graph (elevation vs. distance) alongside its segmented slope analysis.

Inputs (7)

  • Curves (Curve): 3D curves representing road centerlines
  • Threshold (Number): Slope threshold
  • Segment Size (Number): Size of segments for analysis
  • Threshold Mode (Integer): 0: Degrees, 1: Percentage, 2: Ratio 1:X
  • Z Exaggeration (Number): Vertical scale multiplier for the profile graph
  • Reference Y (Number): Base elevation (Y-coordinate) to drop alignment lines down to
  • Base Plane (Plane): Origin plane for the unrolled profile graph

Outputs (10)

  • Profile Curves (Curve): Continuous unrolled 2D profile curve
  • Analyzed Segments (Curve): 2D lines representing the slope segments
  • Slope Values (Number): Slope values for each segment
  • Center Points 2D (Point): 2D center points for tagging
  • Segment Status (Text): Status (Compliant / Non-Compliant)
  • Compliance Percentage (Number): Overall compliance percentage
  • Dashboard Data (Text): JSON legend data
  • Alignment Lines (Curve): Vertical lines dropping from breakpoints to Ref Y
  • Alignment Labels (Text): Structural geometry labels (Line, Arc, Spline)
  • Alignment Points (Point): Placement points for alignment labels
