Site Analysis Nickname: Metrics

Overview

Collects Dashboard Data from any analysis components plus your own metrics into one report module file (04_metrics/<module>.json: metrics, green/amber/red flags, maps, sources, plugin version), ready for the report and its scorecard.

Inputs (18)

  • Module (Text): Report module code, e.g. C1, C2, D1, F2
  • Dashboard Data (Text): Dashboard Data JSON from any Enzyme analysis components (one per item)
  • Prefixes (Text): Optional key prefix per Dashboard item, e.g. 'slope', 'wind_ne', 'storm_100y'
  • Keys (Text): Extra metric keys, e.g. elev_min_m, retention_volume_m3
  • Values (Number): Values for Keys (same order)
  • Units (Text): Units for Keys (m, ha, %, m3...)
  • Scopes (Text): Scope per key: site (default), buffer_1km, buffer_5km...
  • FlagThemes (Text): Scorecard themes, e.g. Buildability, Flood & drainage, Climate comfort
  • FlagKeys (Text): Metric key rated for each theme
  • Amber (Number): Amber threshold per flag
  • Red (Number): Red threshold per flag (Red > Amber: higher is worse; Red < Amber: lower is worse)
  • Sources (Text): Input datasets as 'dataset | version | resolution | date'
  • Maps (Text): Map image files for this module (e.g. from Export Views)
  • Captions (Text): Caption per map
  • Confidence (Text): field-verified, modelled or estimated
  • Folder (Text): Project folder (04_metrics is added) or the 04_metrics folder itself
  • Merge (Boolean): Keep metrics already in the file from other definitions and replace only this run's keys
  • Write (Boolean): Write the file (use a button)

Outputs (5)

  • JSON (Text): The module file content
  • Scorecard (Text): Theme: rating (value vs thresholds)
  • Metrics (Text): key = value unit, for checking
  • File (Text): Path written (empty until Write)
  • Info (Text): Component information and interpretation
