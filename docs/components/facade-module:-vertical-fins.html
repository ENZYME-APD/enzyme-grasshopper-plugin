Facade Module: Vertical Fins

Generates patterned vertical fins, spandrels, and vision glass.

JSON Masterplan (Beta) Nickname: Mod_Fins

Overview

Generates patterned vertical fins, spandrels, and vision glass.

Inputs (8)

  • Bounds (Curve): Boundary curves
  • Heights (Number): Heights
  • Spacing (Number): Spacing
  • Depth (Number): Depth
  • HeaderDrop (Number): Header Drop
  • HorizPattern (Text): Horizontal Pattern
  • VertPattern (Text): Vertical Pattern
  • FlipDir (Boolean): Flip Direction

Outputs (4)

  • Glass (Brep): Vision Glass
  • Spandrels (Brep): Spandrels
  • Fins (Brep): Fins
  • Info (Text): Method, assumptions, simplifications and references.

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. Each boundary curve (one per floor, height from Heights by path and index, default 4.0 m) is extruded straight up along world Z, whatever its orientation, into glass up to height - HeaderDrop, and a spandrel band of HeaderDrop above it.
  2. The curve is split into its segments; each segment is divided into round(length / Spacing) equal parts (at least 1), so fins sit at both ends and the real spacing is close to Spacing. Points repeated at shared corners (within 1 mm) are used once.
  3. Fin positions are numbered along the whole curve; a fin is placed where the active horizontal pattern has 1 (the pattern repeats).
  4. The active pattern for the i-th curve in a branch is HorizPattern[VertPattern digit i] (both wrap round), so VertPattern picks a pattern per floor.
  5. Each fin is a flat surface Depth deep, perpendicular to the segment on its left side (FlipDir reverses), and the full floor height tall.
  6. The HUD reports fin count and glass and spandrel areas (curve length × height).

Assumptions

  • Bounds are horizontal facade lines or outlines at each floor level; units are metres.
  • Defaults: Spacing 1.5 m, Depth 0.3 m, HeaderDrop 0 m; non-positive Spacing or Depth fall back to the defaults.

Simplifications and limits

  • All parts are zero-thickness surfaces; no mullions, frames or slab edges.
  • Fins are not adjusted at corners; patterns ignore segment breaks.
  • VertPattern is indexed by the item index within a branch, so each branch must hold one building's floors in order.

Workflow

  • Facade JSON Parser BoundsExt and Heights -> Bounds and Heights; outputs -> Custom Preview or bake.
