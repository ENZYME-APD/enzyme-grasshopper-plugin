Site Analysis Nickname: SiteFetch

Overview

Downloads open data for a site (terrain, land cover, OSM buildings and trees) and builds it as geometry in local metres. Site centre = 0,0 in UTM; see Georeference.

Inputs (14)

  • Latitude (Number): Site centre latitude (WGS84 degrees).
  • Longitude (Number): Site centre longitude (WGS84 degrees).
  • Size (Number): Side of the square site in metres (max 5000).
  • Cell Size (Number): Terrain and land cover mesh cell size in metres. Terrain source is 30 m, land cover 10 m.
  • Buildings (Boolean): Fetch OSM buildings.
  • Trees (Boolean): Fetch OSM individual trees (natural=tree).
  • Land Cover (Boolean): Fetch ESA WorldCover land cover.
  • Default Height (Number): Height for buildings with no height or levels tag (m).
  • Level Height (Number): Storey height used to convert building:levels to metres.
  • Tree Height (Number): Height for trees with no height tag (m).
  • Crown Diameter (Number): Crown diameter for trees with no diameter_crown tag (m).
  • Cache Folder (Text): Optional folder for downloaded data. Default: %LOCALAPPDATA%/Enzyme/SiteFetch. Re-runs read from here.
  • Overpass URL (Text): Optional Overpass API endpoint for OSM data.
  • Run (Boolean): Download and build. Use a button or toggle: nothing is downloaded until Run is true.

Outputs (12)

  • Terrain (Mesh): Terrain mesh (Copernicus GLO-30, EGM2008 heights in m).
  • Land Cover (Mesh): Terrain mesh coloured by ESA WorldCover class (one colour per cell).
  • Land Cover Class (Integer): WorldCover class code per land cover cell (10 tree cover, 50 built-up, 80 water, ...).
  • Buildings (Brep): OSM buildings as closed extrusions standing on the terrain.
  • Building Mesh (Mesh): All buildings joined in one mesh: plug into Context of Sun Hours, Fast CFD, etc.
  • Building Heights (Number): Height of each building (m, eaves to ground, from OSM height / levels or the default).
  • Tree Crowns (Mesh): Closed crown meshes: plug into Trees of Sun Hours.
  • Tree Points (Point): Trunk base points on the terrain.
  • Boundary (Curve): Site boundary square.
  • Georeference (Text): JSON: UTM zone, EPSG, easting/northing of the local origin, lat/lon.
  • Dashboard Data (Text): JSON legend, site metrics and land cover areas (for Report Metrics).
  • Sources (Text): Data sources and required attribution.
