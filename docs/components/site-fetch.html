Site Analysis Nickname: SiteFetch

Overview

Downloads open data for a site (terrain, land cover, OSM buildings and trees) and builds it as geometry in local metres. Site centre = 0,0 in UTM; see Georeference.

Inputs (14)

  • Latitude (Number): Site centre latitude (WGS84 degrees).
  • Longitude (Number): Site centre longitude (WGS84 degrees).
  • Size (Number): Side of the square site in metres (max 5000).
  • Cell Size (Number): Terrain and land cover mesh cell size in metres. Terrain source is 30 m, land cover 10 m.
  • Buildings (Boolean): Fetch OSM buildings.
  • Trees (Boolean): Fetch OSM individual trees (natural=tree).
  • Land Cover (Boolean): Fetch ESA WorldCover land cover.
  • Default Height (Number): Height for buildings with no height or levels tag (m).
  • Level Height (Number): Storey height used to convert building:levels to metres.
  • Tree Height (Number): Height for trees with no height tag (m).
  • Crown Diameter (Number): Crown diameter for trees with no diameter_crown tag (m).
  • Cache Folder (Text): Optional folder for downloaded data. Default: %LOCALAPPDATA%/Enzyme/SiteFetch. Re-runs read from here.
  • Overpass URL (Text): Optional Overpass API endpoint for OSM data.
  • Run (Boolean): Download and build. Use a button or toggle: nothing is downloaded until Run is true.

Outputs (13)

  • Terrain (Mesh): Terrain mesh (Copernicus GLO-30, EGM2008 heights in m).
  • Land Cover (Mesh): Terrain mesh coloured by ESA WorldCover class (one colour per cell).
  • Land Cover Class (Integer): WorldCover class code per land cover cell (10 tree cover, 50 built-up, 80 water, ...).
  • Buildings (Brep): OSM buildings as closed extrusions standing on the terrain.
  • Building Mesh (Mesh): All buildings joined in one mesh: plug into Context of Sun Hours, Fast CFD, etc.
  • Building Heights (Number): Height of each building (m, eaves to ground, from OSM height / levels or the default).
  • Tree Crowns (Mesh): Closed crown meshes: plug into Trees of Sun Hours.
  • Tree Points (Point): Trunk base points on the terrain.
  • Boundary (Curve): Site boundary square.
  • Georeference (Text): JSON: UTM zone, EPSG, easting/northing of the local origin, lat/lon.
  • Dashboard Data (Text): JSON legend, site metrics and land cover areas (for Report Metrics).
  • Sources (Text): Data sources and required attribution.
  • Info (Text): Method, assumptions, simplifications and references.

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. Local frame: UTM zone of the site centre (Krüger series, WGS84); the centre is moved to 0,0 so Rhino keeps full precision. Georeference gives the EPSG code and the origin easting and northing.
  2. Terrain: Copernicus DEM GLO-30 tiles (1 degree, Cloud-Optimised GeoTIFF) read with HTTP range requests, so only the needed tiles and blocks are downloaded; heights are sampled bilinearly at every grid vertex.
  3. Land cover: ESA WorldCover 2021 v200 (10 m) sampled at each cell centre (nearest pixel) and coloured with the official class colours.
  4. Buildings and trees: OpenStreetMap through the Overpass API (ways and multipolygon relations tagged building, nodes tagged natural=tree), with a margin round the site.
  5. Building height = height tag; else building:levels × Level Height (+ half of roof:levels); else Default Height. min_height or building:min_level lifts the underside.
  6. Each building is a closed extrusion standing at the lowest terrain level under its footprint; courtyards (inner rings) are kept.
  7. Each tree is a closed crown: a sphere of radius min(crown diameter / 2, 0.45 × height) touching the tree top.
  8. Downloads are cached on disk, so a re-run of the same site reads from the cache.

Assumptions

  • Copernicus GLO-30 is a surface model (DSM): in towns and forests it includes some building and canopy height, smoothed to 30 m. Treat it as terrain for site-scale studies, not for detailed grading.
  • Heights are orthometric (EGM2008 geoid), not ellipsoidal.
  • OpenStreetMap completeness and tagging vary by place: untagged buildings get the Default Height (the Dashboard shows the share with real height data).
  • A building belongs to the site when the centre of its largest outline is inside the square.
  • Land cover is the 2021 snapshot.

Simplifications and limits

  • Flat roofs: roof shapes are not modelled; building:part pieces are not used.
  • Buildings sit on one base level (no stepped bases on slopes).
  • Tree crowns are spheres; tree heights and crown diameters default when not tagged.
  • Rhino Y is UTM grid north, which differs slightly from true north away from the zone centre.
  • Sites up to 5 km square; sea tiles with no DEM get elevation 0.

Workflow

  • Run once per site (Run gate). Building Mesh -> Context of Sun Hours, Fast CFD, noise. Tree Crowns -> Trees of Sun Hours. Terrain -> Hydro-DEM, Road Corridor.
  • Put the Sources text on every drawing or report that uses the data (OpenStreetMap attribution is required).

References

  • Copernicus DEM GLO-30, ESA / Airbus, distributed on AWS Open Data.
  • Zanaga D. et al. (2022), ESA WorldCover 10 m 2021 v200, CC BY 4.0.
  • OpenStreetMap contributors (ODbL); Overpass API.
  • Karney C.F.F. (2011), Transverse Mercator with an accuracy of a few nanometers (Krüger series).
