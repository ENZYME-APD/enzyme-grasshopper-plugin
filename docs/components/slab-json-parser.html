Slab JSON Parser

Parses Slab JSON data.

JSON Masterplan (Beta) Nickname: Slab_Parser

Overview

Parses Slab JSON data.

Inputs (5)

  • Slab_JSON (Text): JSON string for slabs
  • Filter_Building (Text): Building filters
  • Filter_Tower (Text): Tower filters
  • Filter_Level (Integer): Level filters
  • ExactMatch (Boolean): Use exact matching

Outputs (3)

  • SlabBounds (Curve): Slab boundary curves
  • Areas (Number): Slab areas
  • Labels (Text): Slab labels

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. Reads the slab JSON (building name -> list of slabs with tower_id, floor_index, true_z, area and boundary) and keeps slabs whose building, tower and level pass the filters.
  2. Filters are case-insensitive; with ExactMatch False a filter matches if contained in the name, or as a wildcard pattern with * and ?; empty filters accept everything.
  3. Each boundary is rebuilt from Line, Arc and Polyline segments, joined (0.01 tolerance), closed if needed and moved up by true_z. Output paths are building index; slab index.
  4. Areas are read from the JSON, not recomputed; Labels read building | tower - Lvl level.

Assumptions

  • The JSON comes from the Masterplan Engine Slab_JSON output, with boundary curves at Z = 0.

Simplifications and limits

  • If a boundary does not join into one curve only the first joined piece is kept and a warning is shown; missing point coordinates default to the origin.

Workflow

  • Masterplan Engine Slab_JSON -> Slab_JSON -> facade modules or area schedules.
