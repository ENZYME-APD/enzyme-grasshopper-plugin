Slab JSON Parser

Masterplan Nickname: Slab_Parser

Overview

Parses Slab JSON data.

Inputs (5)

  • Slab_JSON (Text): JSON string for slabs
  • Filter_Building (Text): Building filters
  • Filter_Tower (Text): Tower filters
  • Filter_Level (Integer): Level filters
  • ExactMatch (Boolean): Use exact matching

Outputs (3)

  • SlabBounds (Curve): Slab boundary curves
  • Areas (Number): Slab areas
  • Labels (Text): Slab labels
