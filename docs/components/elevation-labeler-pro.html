Elevation Labeler Pro

Custom text/elevation labels with radial rotation and auto-sync.

Terrain Nickname: ELEV_LABEL

Overview

Custom text/elevation labels with radial rotation and auto-sync.

Inputs (11)

  • Points (Point): Coordinates to label
  • LabelText (Text): Optional text override
  • Length (Number): Leader line length
  • Gap (Number): Gap between line and text
  • Style (Text): Rhino Text Style name
  • TextPlane (Integer): 0=XY, 1=XZ, 2=YZ
  • Orientation (Number): Rotation in degrees
  • Anchor (Integer): 1-9 Justification
  • Bake (Boolean): Bake toggle/button
  • BakeLayer (Text): Target bake layer
  • BakeName (Text): Substitution group ID

Outputs (3)

  • LeaderLine (Curve): Generated leader lines
  • Text (Generic): Generated text entities
  • Instructions (Text): Contract constraints
