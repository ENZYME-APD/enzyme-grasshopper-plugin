Site Analysis Nickname: Probe

Overview

Reads analysis values at any points (entrances, seating, play areas...). Interpolates within the mesh face, works for several result sets at once (options, hours) and writes a CSV table for reports.

Inputs (8)

  • Mesh (Mesh): Analysis mesh
  • Values (Number): One value per vertex or per face. Several branches = several result sets (options, hours); each becomes a CSV column
  • Points (Point): Points to probe
  • Names (Text): Optional name per point (default P1, P2...)
  • SetNames (Text): Optional name per result set / branch (default from branch path)
  • MaxDistance (Number): Points further than this from the mesh get no value (0 = no limit)
  • Decimals (Integer): Decimals in labels and CSV
  • Unit (Text): Unit shown in the labels, e.g. m/s, dB, h

Outputs (5)

  • Values (Number): Probed value per point (one branch per result set, same order as Points). Empty where the point is off the mesh
  • MeshPoints (Point): Closest point on the mesh for each probe (label anchors)
  • Labels (Text): Name: value text per point (first result set; all sets when there are several)
  • CSV (Text): Table Name,X,Y,Z,<set 1>,<set 2>... (paste into Excel or write with a file writer)
  • Info (Text): Component information and interpretation
