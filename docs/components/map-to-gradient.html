Map to Gradient

Remaps a list of numbers into a gradient of colors.

Utilities Nickname: GradientMap

Overview

Remaps a list of numbers into a gradient of colors.

Inputs (3)

  • Values (Number): List of numbers to map to colors.
  • Source Domain (Interval): Optional source domain. If left empty, it automatically uses the min and max of the input values.
  • Colors (Colour): List of colors to form the gradient. Defaults to a standard Blue-to-Red spectrum if empty.

Outputs (1)

  • Mapped Colors (Colour): The resulting interpolated colors.
