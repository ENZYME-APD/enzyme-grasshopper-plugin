Overview

Creates a legend of colors with geometric representation

Inputs (3)

  • Color Legend (Generic): Legend data from analysis components
  • Base Point (Point): Base point for legend placement
  • Scale (Number): Scale factor for legend geometry

Outputs (4)

  • Legend Rectangles (Curve): Rectangle curves for legend
  • Legend Labels (Text): Text labels for legend
  • Label Positions (Point): Positions for text labels
  • Legend Colors (Colour): Colors for legend elements
