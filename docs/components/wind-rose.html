Site Analysis Nickname: WindRose

Overview

Wind rose from an EPW weather file (or direction/speed lists), drawn in the Rhino viewport on site and/or as a screen HUD. A 0-360 selector picks a direction and outputs its speed and frequency, ready for Fast CFD. Directions are meteorological: where the wind blows FROM, 0 = North, clockwise.

Inputs (19)

  • EPW (Text): Path to an EPW weather file (e.g. from climate.onebuilding.org).
  • Directions (Number): Alternative to EPW: wind directions in degrees (FROM, 0 = N, clockwise).
  • Speeds (Number): Alternative to EPW: wind speeds (m/s), same length as Directions.
  • Selector (Number): Direction to inspect, 0-360 degrees (FROM, 0 = N). Drives the Direction/Speed/Frequency outputs and the highlight.
  • Sectors (Integer): Number of direction sectors (8, 16, 36...).
  • Speed Classes (Number): Lower edges of the speed bands in m/s (last band is open-ended).
  • Speed Stat (Integer): Speed output for the selected sector: 0 = Mean, 1 = Median, 2 = P90, 3 = Max.
  • Months (Integer): Optional months to include (1-12), e.g. summer only. EPW only.
  • Hours (Integer): Optional hours of day to include (0-23), e.g. 8-20 for daytime. EPW only.
  • Plane (Plane): Where the rose sits in the model (centre and orientation).
  • Radius (Number): Rose radius in model units; the busiest sector reaches it.
  • North (Number): Angle of true north from the model +Y axis, degrees counter-clockwise (Ladybug convention).
  • Colors (Colour): Optional colours for the speed bands (low to high), e.g. from Color Palette.
  • Display (Integer): 0 = on site (world), 1 = screen HUD, 2 = both.
  • HUD Size (Integer): Screen HUD rose diameter in pixels.
  • HUD Anchor (Integer): Screen HUD corner: 0 = top left, 1 = top right, 2 = bottom left, 3 = bottom right.
  • Text Size (Number): Label size in pixels (viewport labels and HUD).
  • Calm (Number): Speeds below this (m/s) count as calm and are left out of the sectors.
  • Run (Boolean): Optional. False = keep showing the last rose (cached). Share one toggle with the Analysis Dashboard to switch everything on/off together.

Outputs (10)

  • Direction (Number): Selected direction in degrees (FROM, 0 = N) — plug into Fast CFD Direction.
  • Speed (Number): Wind speed of the selected sector (m/s, statistic chosen by Speed Stat) — plug into Fast CFD WindSpeed.
  • Frequency (Number): Share of all hours the wind blows from the selected sector (%).
  • Rose (Mesh): Coloured rose mesh (bakeable).
  • Guides (Curve): Frequency rings, compass axes, selected-sector outline and wind arrow (bakeable).
  • Label Points (Point): Positions for the labels (bake with Text Tag / text).
  • Labels (Text): Label text matching Label Points.
  • Sector Table (Text): Frequency (%) per sector and speed band, tab-separated.
  • Dashboard Data (Text): JSON for the Analysis Dashboard.
  • Info (Text): Source, period, calm share and how to read the rose.

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. Reads wind direction (field 21) and speed (field 22) from every EPW hour, optionally filtered by Months and Hours (EPW hour 1-24 is taken as the hour starting one earlier); 999 codes are skipped. Or uses the Directions and Speeds lists.
  2. Hours with speed below Calm (default 0.5 m/s) are counted as calm. The others are binned into Sectors (default 16, 4-72) centred on N and into speed bands (lower edges, default 0, 2, 4, 6, 8, 10 m/s).
  3. Frequency = hours in a sector and band / all hours (calm included) × 100.
  4. Petals start at a calm circle of 0.12 × Radius and grow linearly with frequency up to Radius at the top ring (rounded up to a nice step), stacked by speed band, with a 10 % gap between sectors. Bearings are turned into the model with North (degrees anticlockwise from +Y).
  5. The Selector picks a sector; Speed is the mean, median, P90 (linear interpolation) or max of its non-calm hours, Frequency its share. Direction is the Selector angle; Speed and Frequency are statistics of the whole sector containing it (a remark names the sector centre when they differ).

Assumptions

  • Directions are meteorological (where the wind comes FROM, 0 = N, clockwise); EPW speeds are 10 m station values.
  • The weather station represents the site.

Simplifications and limits

  • Counts hours only: no correction for height, terrain roughness or local obstacles.
  • All filtered hours weigh the same; calm hours have no direction.

Workflow

  • EPW file path -> EPW; Direction and Speed -> Fast CFD Direction and WindSpeed; Dashboard Data -> Analysis Dashboard.

References
