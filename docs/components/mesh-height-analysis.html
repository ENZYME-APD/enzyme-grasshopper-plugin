Mesh Height Analysis

Terrain

Analyzes mesh extremes, unrolls sections bi-directionally, and generates 3D/2D metadata labels.

Description

Analyzes terrain models to find local peaks, global maximums and minimums, and generates dynamic cross sections in both X and Y directions. Includes functionality to unroll sections flat onto the XY plane alongside the terrain.

Inputs

NameTypeAccessDescription
TargetMeshesMeshTreeThe meshes to analyze.
SearchRingsIntegerItemTopological radius in rings.
ProminenceLimitNumberItemMinimum Z-delta to be considered a peak/valley.
CustomColorsColorListCustom colormap list (Optional).
CullGlobalsBooleanItemToggle to remove the absolute highest/lowest points.
AvoidBoundariesBooleanItemToggle to ignore naked edge vertices.
EnableHeatmapBooleanItemToggle to compute and output the vertex heatmap mesh.
RotationPlanePlaneItemOrientation plane for the bounding box sectioning.
SectionsXIntegerItemNumber of sections running parallel to the X-axis.
SectionsYIntegerItemNumber of sections running parallel to the Y-axis.
LayoutFlatBooleanItemToggle to generate 2D XY print layouts next to the mesh.

Outputs

NameTypeAccessDescription
LocalPeaksPointTreeOutput points for local highs.
PeakElevationsNumberTreeZ-values for local highs.
GlobalMaxPointPointTreeAbsolute highest point on the mesh.
GlobalMaxElevationNumberTreeAbsolute highest Z-value.
LocalValleysPointTreeOutput points for local lows.
ValleyElevationsNumberTreeZ-values for local lows.
GlobalMinPointPointTreeAbsolute lowest point on the mesh.
GlobalMinElevationNumberTreeAbsolute lowest Z-value.
HeatmapMeshesMeshTreeThe vertex-colored duplicate mesh.
SectionOutlinesXCurveTree3D Polylines running parallel to the X-axis.
SectionOutlinesYCurveTree3D Polylines running parallel to the Y-axis.
FlatSectionsXCurveTree2D X-Sections stacked downwards (-Y direction).
FlatSectionsYCurveTree2D Y-Sections stacked leftwards (-X direction).
LabelText3DTextTreeText strings for 3D section labels.
LabelPoints3DPointTreePoints for 3D section labels.
LabelTextFlatTextTreeText strings for the flattened section layout.
LabelPointsFlatPointTreePoints for the flattened section layout.
SectionMetadataTextTreeDictionary keys containing spatial transform & ID data.
