Slope Analysis Mesh SlopeAnalysis

Analyses a mesh topography and provides a coloured mesh displaying areas with slopes over a threshold.

Inputs

Name Nickname Type Access Default Description
Mesh Mesh Mesh Item — Input mesh topography
Start Color Start Color Colour Item Green Colour for areas below threshold
End Color End Color Colour Item Red Colour for areas above threshold
Threshold Threshold Number Item 30.0 Slope threshold in degrees
Binary Mode Binary Mode Boolean Item false Use binary colouring instead of gradient

Outputs

Name Nickname Type Access Description
Slope Mesh Slope Mesh Mesh Item Coloured mesh showing slope distribution
Color Legend Color Legend Generic Item Legend data (start/end colour, threshold, % over threshold)
Percent Over Threshold Percent Over Threshold Number Item Percentage of mesh faces exceeding the slope threshold

Notes & Behaviour

Colour is applied per vertex based on face normals. Gradient mode interpolates linearly between Start and End colour. Binary mode snaps to one of the two colours. Slope angle is measured from vertical (Z-axis). Status message shows mode, percentage over threshold, and execution time.
