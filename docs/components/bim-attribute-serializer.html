BIM Attribute Serializer

Serializes referenced Rhino curves via Attribute User Text.

Masterplan Nickname: BIM_JSON

Overview

Serializes referenced Rhino curves via Attribute User Text.

Inputs (4)

  • Guids (Generic): Referenced Rhino geometry IDs.
  • Refresh (Boolean): Wire a Button to force re-read of attributes.
  • Fillet_Config (Text): JSON string defining fillet rules.
  • PushToRhino (Boolean): Wire a Button to push elevations to Rhino.

Outputs (1)

  • JSON_Payload (Text): Serialized JSON.
