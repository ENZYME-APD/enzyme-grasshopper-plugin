Curve Segment Dispatcher

Explodes curves into Lines and Arcs, extracting Radii, Centers, and visual Dimensions.

Utilities Nickname: SegDisp

Overview

Explodes curves into Lines and Arcs, extracting Radii, Centers, and visual Dimensions.

Inputs (4)

  • curves (Curve): Curves to process
  • offset (Number): Dimension offset
  • dim_toggle (Boolean): Show dimensions
  • num_dec (Integer): Number of decimals

Outputs (5)

  • lines (Curve): Linear segments
  • arcs (Curve): Arc segments
  • radii (Number): Arc radii
  • centers (Point): Arc centers
  • dims (Generic): Visual dimensions
