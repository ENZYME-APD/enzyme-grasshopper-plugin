GroupByKey GrpByKey

Groups a list of values by a corresponding list of keys into a DataTree.

Inputs

Name Nickname Type Access Default Description
Keys Keys Generic List — Keys to group by
List List Generic List — List of values to be grouped (must be same length as Keys)

Outputs

Name Nickname Type Access Description
Unique Keys UniqueKeys Generic List Unique values of the keys
Grouped Values GroupedValues Generic Tree Data tree with values grouped by keys

Notes & Behaviour

Automatically unwraps Grasshopper wrapper types (GH_String, GH_Integer, etc.) for consistent key comparison. The output tree branch index matches the order of first appearance of each unique key. Status message shows item count and group count.
