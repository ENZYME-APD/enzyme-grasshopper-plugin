Terrain Colorizer

Colors a terrain mesh procedurally based on elevation and slope steepness, extracting 1m and 5m contours.

Site Analysis Nickname: TerrainCol

Overview

Colors a terrain mesh procedurally based on elevation and slope steepness, extracting 1m and 5m contours.

Inputs (5)

  • Terrain (Mesh): The input terrain mesh
  • Colors (Colour): Optional list of colors for the elevation gradient (if none, defaults to procedural palette)
  • Cliff Threshold (Number): Slope angle above which a face is considered a cliff (Default 45)
  • Cliff Color (Colour): Color for cliff faces (Default Gray)
  • Flat Threshold (Number): Slope angle below which a face is considered flat (Default 5)

Outputs (3)

  • Colored Terrain (Mesh): The terrain mesh with procedural vertex colors applied
  • Contours (Curve): 1m normal contours
  • Main Contours (Curve): 5m main contours
