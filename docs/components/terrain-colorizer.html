Terrain Colorizer

Colors a terrain mesh by elevation and generates contours.

Site Analysis Nickname: Terrain Color

Overview

Colors a terrain mesh by elevation and generates contours.

Inputs (7)

  • Terrain (Mesh): Input terrain mesh
  • Colors (Colour): List of gradient colors (from low to high). Leaves empty for default palette.
  • Use Slope Color (Boolean): Toggle steep slope coloring
  • Slope Color (Colour): Color applied to sheer cliffs/slopes
  • Slope Angle (Number): Angle in degrees where slope color starts
  • Contour Step (Number): Interval for normal contour lines
  • Main Step (Number): Interval for main contour lines

Outputs (3)

  • Colored Terrain (Mesh): Terrain mesh with vertex colors
  • Contours (Curve): Normal contours
  • Main Contours (Curve): Main contours
