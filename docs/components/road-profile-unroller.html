Masterplan Nickname: UnrollProfile

Overview

Flattens a 3D road centerline into a scaled 2D profile view (Length vs Elevation) onto a custom reference plane, with slope and structural segment labeling.

Inputs (3)

  • Road Curve (Curve): The 3D centerline of the road
  • Plane (Plane): The 2D plane to project the unrolled profile onto (origin)
  • Text Height (Number): Height for the generated text labels

Outputs (3)

  • Unrolled Curve (Curve): The flattened 2D curve
  • Grid Lines (Curve): Vertical projection lines for segment breaks
  • Labels (Text3d): Slope and geometry labels for each segment
