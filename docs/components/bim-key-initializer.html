BIM Key Initializer

Safely injects default BIM attributes (user text keys) into referenced Rhino objects of any type; existing keys are never overwritten.

JSON Masterplan (Beta) Nickname: INITKEYS

Overview

Safely injects default BIM attributes into referenced Rhino curves.

Inputs (2)

  • Guids (Generic): Referenced Rhino geometry IDs.
  • Run (Boolean): Wire a Button here to execute the injection.

Outputs (1)

  • Guids (Generic): Pass-through for the Serializer.

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. Reads the referenced Rhino object IDs (Guid, Guid text or referenced geometry) and, when Run is True, adds default user text keys to each object: BuildingID = Building_01, TowerID = Main_Tower, Program = Residential, Phase = 0, Floors = 1, FloorHeight = 4.0.
  2. Only keys that do not exist yet are written; existing values are never overwritten. The IDs are passed through for the serializer.

Assumptions

  • The inputs are Rhino-referenced objects (Type Hint Guid); objects not found in the active document are skipped and counted.

Simplifications and limits

  • Defaults are fixed in code; edit the values afterwards in Rhino or with the UserText tools.
  • Changes are committed directly and are not grouped as one undo step.

Workflow

  • Referenced curves or Breps (Guid hint) -> Guids. Guids -> the JSON Masterplan serializer.
