Reset Mesh Colors

Strips all vertex colors from a mesh, allowing Custom Preview to override its color natively.

Site Analysis Nickname: Mesh-C-Reset

Overview

Strips all vertex colors from a mesh, allowing Custom Preview to override its color natively.

Inputs (1)

  • Mesh (Mesh): Meshes to clean

Outputs (1)

  • Mesh (Mesh): Cleaned meshes without vertex colors

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. Duplicates each mesh and clears its vertex colours, so Custom Preview can apply its own colour.

Assumptions

  • None beyond valid meshes.

Simplifications and limits

  • None: geometry, normals and texture coordinates are kept.

Workflow

  • Coloured analysis mesh -> Reset Mesh Colors -> Custom Preview.
