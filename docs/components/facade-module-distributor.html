Facade Module Distributor

Dynamically streams procedural facade modules with high-performance hot-reloading.

Facade Nickname: FACADE_DIST

Overview

Dynamically streams procedural facade modules with high-performance hot-reloading.

Inputs (5)

  • Base_Curves (Curve): Floor boundaries to run facade loops against.
  • Floor_Heights (Number): Intended structural heights per level.
  • Local_Repo_Dir (Text): Path to your local git directory OR python file.
  • Dev_Mode (Boolean): True = Local Git Repo | False = Production Github Remote.
  • Force_Update (Boolean): Force a re-download of the remote production scripts.

Outputs (3)

  • Horizontal_Bands (Generic): Horizontal_Bands
  • Storefront_Mullions (Generic): Storefront_Mullions
  • Storefront_Glass (Generic): Storefront_Glass
