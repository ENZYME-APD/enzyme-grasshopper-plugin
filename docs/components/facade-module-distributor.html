Facade Module Distributor

Loads the facade_modules.py Python script (downloaded from GitHub, or a local file in Dev_Mode) and runs it to build facade bands, storefront mullions and glass. A changed script file is re-read the next time the component solves.

Facade Nickname: FACADE_DIST

Overview

Dynamically streams procedural facade modules with high-performance hot-reloading.

Inputs (5)

  • Base_Curves (Curve): Floor boundaries to run facade loops against.
  • Floor_Heights (Number): Intended structural heights per level.
  • Local_Repo_Dir (Text): Path to your local git directory OR python file.
  • Dev_Mode (Boolean): True = Local Git Repo | False = Production Github Remote.
  • Force_Update (Boolean): Force a re-download of the remote production scripts.

Outputs (4)

  • Horizontal_Bands (Generic): Horizontal_Bands
  • Storefront_Mullions (Generic): Storefront_Mullions
  • Storefront_Glass (Generic): Storefront_Glass
  • Info (Text): Method, assumptions, simplifications and references.

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. Closed curves from Base_Curves are collected into one flat list; open curves are ignored.
  2. In production mode the Python file facade_modules.py is downloaded from the ENZYME-APD/Grasshopper-GitHub-test repository (main branch) to the user folder .rhinocode/gh_distributed_scripts when missing or when Force_Update is True. In Dev_Mode it is read from Local_Repo_Dir.
  3. The script text is cached in memory and re-read only when its file modification time changes.
  4. The script is run in Rhino's Python engine, calling generate_horizontal_bands with band_thickness 0.30 and division_count 3, and generate_storefront with mullion_spacing 1.5 and glass_inset 0.05; Floor_Heights defaults to a single 4.0.
  5. Its results are output as Horizontal_Bands, Storefront_Mullions and Storefront_Glass.

Assumptions

  • The geometry logic lives entirely in the external Python script; this component only loads and runs it.
  • Model units are metres (fixed 0.30, 1.5, 0.05 and 4.0 values).

Simplifications and limits

  • Band thickness, division count, mullion spacing and glass inset are hard-coded and cannot be changed from Grasshopper.
  • Data trees are flattened; outputs are flat lists.
