Microclimate Comfort

Calculates the perceived 'Feels Like' temperature using Fast Apparent Temperature or Precise UTCI.

Site Analysis Nickname: FeelsLike

Overview

Calculates the perceived 'Feels Like' temperature using Fast Apparent Temperature or Precise UTCI.

Inputs (6)

  • Points (Point): Analysis points.
  • Air Temp (Number): Air temperature in Celsius.
  • Humidity (Number): Relative humidity in %.
  • Wind Speed (Number): Wind speed in m/s at 10m height.
  • Solar Factor (Number): Solar exposure from 0.0 (shade) to 1.0 (sun).
  • Method (Integer): 0 = Fast Apparent Temp, 1 = Precise UTCI

Outputs (5)

  • Points (Point): Analysis points.
  • Feels Like (Number): Perceived temperature in Celsius.
  • Category (Text): Comfort category label.
  • Colors (Colour): Gradient color mapping.
  • Dashboard Data (Text): JSON Legend Data
