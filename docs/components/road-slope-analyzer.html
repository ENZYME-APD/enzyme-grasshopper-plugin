Road Slope Analyzer

Analyzes road slopes by projecting 2D curves onto a terrain mesh

Masterplan Nickname: RoadSlope

Overview

Analyzes road slopes by projecting 2D curves onto a terrain mesh

Inputs (5)

  • Curves (Curve): 2D curves representing roads
  • Terrain (Mesh): Terrain mesh for projection
  • Threshold (Number): Slope threshold
  • Segment Size (Number): Size of segments for analysis
  • Threshold Mode (Integer): 0: Degrees, 1: Percentage, 2: Ratio 1:X

Outputs (8)

  • Analyzed Segments (Curve): Road segments with slope analysis
  • Slope Values (Number): Slope values for each segment
  • Center Points (Point): Center points of segments
  • Compliance Percentage (Number): Percentage of compliant/non-compliant segments
  • Projected Points (Point): Points projected onto terrain
  • Projection Lines (Line): Lines showing projection from original to terrain
  • Dashboard Data (Text): JSON legend data
  • Info (Text): Method, assumptions, simplifications and references.

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. Each curve is divided into ceil(length / Segment Size) pieces by equal parameter steps.
  2. Both ends of each piece are dropped vertically onto the Terrain (ray from above the mesh; if that misses, from below).
  3. The slope of the straight chord between the two projected points is computed as degrees atan(Δz / Δxy), percentage Δz / Δxy × 100, or ratio Δxy / Δz (Threshold Mode 0, 1, 2).
  4. A piece is compliant if its slope is at or below Threshold (for the ratio mode, at or above Threshold). Results go to branch 0 (compliant) or 1 (non-compliant); Compliance Percentage is the share of compliant pieces by count.

Assumptions

  • Curves lie roughly in plan over the terrain; their own Z is ignored.
  • The top-most terrain surface is the road surface.

Simplifications and limits

  • A vertical piece reads 90 degrees, infinite percent or 1:0 and is never compliant; in ratio mode a flat piece is infinite and compliant.
  • Slope is a straight chord between piece ends; bumps inside a piece are not seen.
  • Compliance is by number of pieces, not by length.
  • No cross slope, no vertical curve design; this checks existing ground along the alignment only.

Workflow

  • Road centrelines and Terrain Mesher output -> Curves and Terrain.
  • Dashboard -> Analysis Dashboard legend.
