Road Slope Analyzer

Analyzes road slopes by projecting 2D curves onto a terrain mesh

Terrain Nickname: RoadSlope

Overview

Analyzes road slopes by projecting 2D curves onto a terrain mesh

Inputs (5)

  • Curves (Curve): 2D curves representing roads
  • Terrain (Mesh): Terrain mesh for projection
  • Threshold (Number): Slope threshold in percentage
  • Segment Size (Number): Size of segments for analysis
  • Ray Upward (Boolean): Cast rays upward instead of both directions

Outputs (6)

  • Analyzed Segments (Curve): Road segments with slope analysis
  • Slope Values (Number): Slope values for each segment
  • Center Points (Point): Center points of segments
  • Compliance Percentage (Number): Percentage of compliant/non-compliant segments
  • Projected Points (Point): Points projected onto terrain
  • Projection Lines (Line): Lines showing projection from original to terrain
