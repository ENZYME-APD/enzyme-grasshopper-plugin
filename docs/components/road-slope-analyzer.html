Road Slope Analyzer RoadSlope

Analyzes road slopes by projecting 2D curves onto a terrain mesh, computing slope percentage per segment.

Inputs

Name Nickname Type Access Default Description
Curves Curves Curve List — 2D curves representing roads
Terrain Terrain Mesh Item — Terrain mesh for projection
Threshold Threshold Number Item 8.0 Slope threshold in percentage
Segment Size Segment Size Number Item 5.0 Size of segments for analysis
Ray Upward Ray Upward Boolean Item false Cast rays upward instead of both directions

Outputs

Name Nickname Type Access Description
Analyzed Segments Analyzed Segments Curve Tree Road segments: branch 0 = compliant, branch 1 = non-compliant
Slope Values Slope Values Number Tree Slope percentage for each segment (same tree structure)
Center Points Center Points Point Tree Center point of each analysed segment
Compliance Percentage Compliance Percentage Number Item Percentage of segments within the threshold
Projected Points Projected Points Point Tree Points projected onto the terrain surface
Projection Lines Projection Lines Line Tree Lines from original point to projected terrain point

Notes & Behaviour

Projects points vertically onto the mesh using ray casting. Falls back to upward ray if downward misses. Slope = (vertical rise / horizontal run) × 100. Output tree branch 0 = compliant segments, branch 1 = non-compliant. Status message shows compliance %, non-compliance %, and execution time.
