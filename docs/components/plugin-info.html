Info Nickname: EnzVer

Overview

Outputs the current version and build date of the Enzyme plugin.

Inputs (0)

  • None

Outputs (2)

  • Version (Text): Current plugin version
  • Build Date (Text): Date and time of the last plugin update

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. Outputs the Enzyme assembly version number and the last-write date and time of the plugin file on disk (local time, yyyy-MM-dd HH:mm:ss).

Assumptions

  • The file date reflects the install or copy time, which normally matches the build.

Simplifications and limits

  • Build Date is the file modification time, not a build stamp embedded in the assembly; it reads Unknown if the file cannot be found.
