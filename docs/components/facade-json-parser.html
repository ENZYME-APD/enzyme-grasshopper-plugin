Facade JSON Parser

Parses Facade JSON data into Curves, Heights, and Programs.

JSON Masterplan (Beta) Nickname: Facade_Parser

Overview

Parses Facade JSON data into Curves, Heights, and Programs.

Inputs (6)

  • Facade_JSON (Text): JSON string representing facade data
  • Filter_Building (Text): Filter by building name
  • Filter_Tower (Text): Filter by tower ID
  • Filter_Program (Text): Filter by program name
  • Filter_Level (Integer): Filter by level index
  • ExactMatch (Boolean): Require exact match for filters

Outputs (5)

  • BoundsExt (Curve): Open Exterior Physical Lines
  • BoundsClosed (Curve): Closed Master Polygon for orientation
  • Heights (Number): Floor-to-floor height
  • Programs (Text): Tags/Labels
  • Info (Text): Method, assumptions, simplifications and references.

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. Expects JSON of the form building -> program -> list of floors, each floor with tower_id, floor_index, true_z, height, BoundsClosed and BoundsExt (segment lists of Line, Arc or Polyline).
  2. Buildings, programs, towers and levels are filtered. Text filters match if any entry matches: ExactMatch True needs equal text (case-insensitive); otherwise the entry is contained in the name, or used as a wildcard pattern with * and ?.
  3. Segments are rebuilt and joined (0.01 tolerance); BoundsClosed takes the first joined curve and closes it if open; floors without a BoundsClosed polygon give a null item (kept for index alignment) and a warning. All curves are moved up by true_z.
  4. For every exterior curve one item is output in each tree: the curve, the closed outline, the floor height and a label building | tower | program - Lvl n. Branch paths are (building index; program index).

Assumptions

  • The JSON is a facade export with the keys above (not the BIM Attribute Serializer payload).
  • Segment coordinates are relative to the floor level; true_z gives the absolute level.

Simplifications and limits

  • Missing true_z or height read as 0; missing floor_index reads as -1.
  • Branch indices count only the buildings and programs that pass the filters, so paths shift when filters change.

Workflow

  • Facade JSON text -> Facade_JSON; BoundsExt and Heights -> facade modules such as Facade Module: Vertical Fins or Rhythmic Balconies.
