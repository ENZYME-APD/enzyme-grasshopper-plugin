Facade JSON Parser

Parses Facade JSON data into Curves, Heights, and Programs.

Masterplan Nickname: Facade_Parser

Overview

Parses Facade JSON data into Curves, Heights, and Programs.

Inputs (6)

  • Facade_JSON (Text): JSON string representing facade data
  • Filter_Building (Text): Filter by building name
  • Filter_Tower (Text): Filter by tower ID
  • Filter_Program (Text): Filter by program name
  • Filter_Level (Integer): Filter by level index
  • ExactMatch (Boolean): Require exact match for filters

Outputs (4)

  • BoundsExt (Curve): Open Exterior Physical Lines
  • BoundsClosed (Curve): Closed Master Polygon for orientation
  • Heights (Number): Floor-to-floor height
  • Programs (Text): Tags/Labels
