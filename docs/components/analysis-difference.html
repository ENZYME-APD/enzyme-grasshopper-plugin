Site Analysis Nickname: Diff

Overview

Compares two design options (or two hours) analysed on the same mesh: A - B map on a diverging scale centred on zero, with area-weighted % increased / decreased and the share of area above a level in each option.

Inputs (10)

  • Mesh (Mesh): Analysis mesh shared by both options (same grid)
  • ValuesA (Number): Values of option A (one per vertex or per face)
  • ValuesB (Number): Values of option B, same count and order as A
  • Threshold (Number): Changes smaller than this count as 'no change' (e.g. 0.5 m/s, 1 dB)
  • Range (Number): Colour scale +-Range (default: largest absolute difference). Use the same Range for every comparison
  • Level (Number): Optional: report the % of area above this level in A and in B (e.g. 5 m/s comfort limit, 55 dB)
  • BetterWhen (Text): Lower, Higher or None: names the change as improvement / worsening in the stats
  • Palette (Text): Diverging palette (Balance, RdBu, Delta, Vlag, PuOr, BrBG...)
  • Mask (Boolean): Optional: one bool per face, True = building / no data
  • Run (Boolean): Optional. False = skip the analysis and keep showing the last results (cached). Share one toggle with the Analysis Dashboard to switch everything on/off together.

Outputs (6)

  • Difference (Number): A - B for every vertex / face (feed Analysis Heatmap with Min = -Range, Max = Range for contours)
  • Heatmap (Mesh): Difference map on the diverging scale
  • Range (Number): Symmetric colour range used
  • Stats (Text): Area-weighted comparison, ready for a report table
  • Dashboard Data (Text): JSON legend payload for Legend Geometry / Analysis Dashboard
  • Info (Text): Component information and interpretation

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. Difference = ValuesA minus ValuesB for every vertex or face (detected from the count; A and B must have the same count).
  2. Area weights: per-face values use the face area; per-vertex values get an equal share (1/3 or 1/4) of the area of every unmasked face they belong to. Masked faces are excluded.
  3. Stats (area-weighted): mean change, % of area where the change is above +Threshold, below minus Threshold or within it, the largest increase and decrease, and with Level set the % of area above Level in A and in B (strictly greater).
  4. Colours: Palette (default Balance) sampled at 0.5 + 0.5 × Difference / Range, clamped, so zero sits at the centre. Range defaults to the largest absolute difference; masked cells are grey.
  5. BetterWhen (Lower or Higher) only renames the increased / decreased lines as improvement or worsening.
  6. Dashboard Data is a legend payload (gradient, labels minus Range and plus Range, stats as metrics).

Assumptions

  • A and B were computed on the same mesh with the same vertex or face order.
  • Face areas are in model units² and the model is planar enough for triangle area sums to be meaningful.

Simplifications and limits

  • No statistical significance: every cell counts by area only.
  • The Difference list still contains values for vertices touched only by masked faces; they are just excluded from the stats and coloured grey.

Workflow

  • Two runs of Fast CFD, Sun Hours, Noise or Analysis Heatmap inputs on the same mesh -> ValuesA, ValuesB.
  • Difference -> Analysis Heatmap with Min = minus Range and Max = Range for contour bands. Dashboard Data -> Report Metrics or Analysis Dashboard.
