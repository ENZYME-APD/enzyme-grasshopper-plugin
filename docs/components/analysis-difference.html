Site Analysis Nickname: Diff

Overview

Compares two design options (or two hours) analysed on the same mesh: A - B map on a diverging scale centred on zero, with area-weighted % increased / decreased and the share of area above a level in each option.

Inputs (9)

  • Mesh (Mesh): Analysis mesh shared by both options (same grid)
  • ValuesA (Number): Values of option A (one per vertex or per face)
  • ValuesB (Number): Values of option B, same count and order as A
  • Threshold (Number): Changes smaller than this count as 'no change' (e.g. 0.5 m/s, 1 dB)
  • Range (Number): Colour scale +-Range (default: largest absolute difference). Use the same Range for every comparison
  • Level (Number): Optional: report the % of area above this level in A and in B (e.g. 5 m/s comfort limit, 55 dB)
  • BetterWhen (Text): Lower, Higher or None: names the change as improvement / worsening in the stats
  • Palette (Text): Diverging palette (Balance, RdBu, Delta, Vlag, PuOr, BrBG...)
  • Mask (Boolean): Optional: one bool per face, True = building / no data

Outputs (6)

  • Difference (Number): A - B for every vertex / face (feed Analysis Heatmap with Min = -Range, Max = Range for contours)
  • Heatmap (Mesh): Difference map on the diverging scale
  • Range (Number): Symmetric colour range used
  • Stats (Text): Area-weighted comparison, ready for a report table
  • Dashboard Data (Text): JSON legend payload for Legend Geometry / Analysis Dashboard
  • Info (Text): Component information and interpretation
