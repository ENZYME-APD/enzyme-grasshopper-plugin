Height Map Analysis Mesh HeightMap

Analyses a mesh topography and provides a coloured mesh displaying height distribution using a multi-colour gradient.

Inputs

Name Nickname Type Access Default Description
Mesh Mesh Mesh Item — Input mesh topography
Color Gradient Color Gradient Colour List — Colours for height gradient (minimum 2 colours)
Flip Colors Flip Colors Boolean Item true Flip the colour gradient direction

Outputs

Name Nickname Type Access Description
Height Mesh Height Mesh Mesh Item Coloured mesh showing height distribution
Color Legend Color Legend Generic Item Legend data with height range and colours

Notes & Behaviour

Multi-stop gradient supported (more than 2 colours). Each vertex is coloured by normalised height (0 = min Z, 1 = max Z). If Flip Colors is true the gradient is reversed before applying. Status message shows height range, colour count, and execution time.
