Adaptive Terrain Grader

TERRAIN GRADER

Generates adaptive grading meshes, volumes, and crisp cut/fill colors.

Description

A powerful tool to adapt existing topography to architectural pads and footprints. This component casts rays to sample an original mesh, dynamically blends the points to given boundary curves based on a maximum angle, and generates a new Delaunay-tessellated mesh. It simultaneously calculates highly accurate Cut and Fill volumes by comparing the modified mesh against the original on an adaptive grid, and generates visual cut/fill coloring using unwelded faces to ensure completely crisp borders.

Inputs

Name Type Access Default Description

Outputs
