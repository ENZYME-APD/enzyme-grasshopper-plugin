Adaptive Terrain Grader

Generates adaptive grading meshes, volumes, and crisp cut/fill colors.

Terrain Nickname: TERRAIN GRADER

Overview

Generates adaptive grading meshes, volumes, and crisp cut/fill colors.

Inputs (7)

  • Mesh (Mesh): Original Topography
  • BoundaryCurves (Curve): Closed pads (Optional)
  • BlendAngle (Number): Max allowable slope in degrees
  • CutColor (Colour): Cut zones color
  • FillColor (Colour): Fill zones color
  • MeshResolution (Number): Base grid size
  • ShowContours (Boolean): Toggle contour generation

Outputs (6)

  • ModMesh (Mesh): Adaptive Tri-Mesh
  • ColoredMesh (Mesh): Unwelded crisp cut/fill visualizer
  • CutVolume (Number): Total Cut (Negative Z)
  • FillVolume (Number): Total Fill (Positive Z)
  • Contours (Curve): 1m Interval Curves
  • MainContours (Curve): 5m Interval Curves
