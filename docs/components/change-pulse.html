Change Pulse

Utilities Nickname: Pulse

Overview

Monitors an input value (like a Slider) and outputs a True pulse (imitating a button) whenever the data changes.

Inputs (1)

  • Data (Generic): Data to monitor (e.g., a Number Slider).

Outputs (1)

  • Pulse (Boolean): Outputs True for one solution when Data changes, then resets to False.
