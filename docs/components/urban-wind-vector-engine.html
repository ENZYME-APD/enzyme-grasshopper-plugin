Urban Wind Vector Engine

Simulates urban wind fields using terrain-parallel raycasting. Outputs a perfectly flat, crisp XY pixel-screen heatmap at a custom elevation.

Terrain Nickname: WindEngine

Overview

Simulates urban wind fields using terrain-parallel raycasting. Outputs a perfectly flat, crisp XY pixel-screen heatmap at a custom elevation.

Inputs (9)

  • Run (Boolean): Global execution toggle switch
  • TerrainMesh (Mesh): The underlying site topography
  • ContextBuildings (Mesh): Lightweight mesh context structures
  • WindDirection (Vector): Travel vector of incoming air
  • WindSpeed (Number): Baseline velocity metric
  • AnalysisHeight (Number): Human pedestrian offset
  • GridSpacing (Number): Resolution size of pixel elements
  • CustomColors (Colour): Custom color spectrum override
  • HeatmapHeight (Number): Z-axis elevation to project the flat heatmap

Outputs (7)

  • VelocityHeatmap (Mesh): Flat, unwelded crisp horizontal pixel-tile matrix
  • WindVectors (Line): Spatial direction markers
  • VectorColors (Colour): Velocity color map matching lines
  • Streamlines (Curve): Continuous particle flow paths
  • VelocityData (Text): Raw velocity values formatted
  • TagPoints (Point): Anchor coordinates for Text Tag
  • PlainMesh (Mesh): Original topography mesh without vertex colors
