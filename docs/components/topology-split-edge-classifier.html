Topology Split Edge Classifier

Explodes and splits room boundaries at intersections, classifies edge topology, and generates unified floor slabs.

Utilities Nickname: TSEC

Overview

Explodes and splits room boundaries at intersections, classifies edge topology, and generates unified floor slabs.

Inputs (2)

  • RoomCurves (Curve): The primary tree of input room boundary curves
  • ToleranceValue (Number): The strict proximity tolerance to merge shared walls

Outputs (5)

  • Instructions_Out (Text): Canvas setup instructions to enforce correct data binding
  • ExternalEdges (Curve): The flattened (Z=0) external boundary curves
  • InternalPartitions (Curve): The flattened (Z=0) internal shared partition curves
  • MetadataOut (Text): JSON serialized spatial parameters for orientation reconstruction
  • FloorSlabs (Curve): The flattened (Z=0) combined boolean union of the rooms
