Topology Split Edge Classifier

Explodes and splits room boundaries at intersections, classifies edge topology, and generates unified floor slabs.

Utilities Nickname: TSEC

Overview

Explodes and splits room boundaries at intersections, classifies edge topology, and generates unified floor slabs.

Inputs (2)

  • TestPoints (Point): The points to test against boundaries
  • BoundaryEdges (Curve): The geometry boundaries or edges
  • SearchRadius (Number): Broad R-Tree clustering radius
  • StrictTolerance (Number): Final topological distance check

Outputs (5)

  • Instructions_Out (Text): Canvas setup instructions to enforce correct data binding
  • FilteredPoints (Point): Points that passed the topology check (flattened to Z=0)
  • MetadataOut (Text): JSON serialized spatial parameters and curve index connections
