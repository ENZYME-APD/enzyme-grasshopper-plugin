Topology Split Edge Classifier

Explodes and splits room boundaries at intersections, classifies edge topology, and generates unified floor slabs.

Utilities Nickname: TSEC

Overview

Explodes and splits room boundaries at intersections, classifies edge topology, and generates unified floor slabs.

Inputs (2)

  • RoomCurves (Curve): Room boundaries as curves
  • ToleranceValue (Number): Tolerance value for intersections

Outputs (5)

  • Instructions_Out (Text): Canvas instructions
  • ExternalEdges (Curve): External boundary edges
  • InternalPartitions (Curve): Internal partition edges
  • MetadataOut (Text): Metadata for edges
  • FloorSlabs (Curve): Unified floor slabs
