Wind Engine

WindEngine

Simulates urban wind fields using terrain-parallel raycasting.

Description

Outputs a perfectly flat, crisp XY pixel-screen heatmap at a custom elevation, illustrating wind direction and speed across topography and built context.

Inputs

NameTypeAccessDescription
RunBooleanItemGlobal execution toggle switch
TerrainMeshMeshItemThe underlying site topography
ContextBuildingsMeshListLightweight mesh context structures (Optional)
WindDirectionVectorItemTravel vector of incoming air
WindSpeedNumberItemBaseline velocity metric
AnalysisHeightNumberItemHuman pedestrian offset
GridSpacingNumberItemResolution size of pixel elements
CustomColorsColorListCustom color spectrum override (Optional)
HeatmapHeightNumberItemZ-axis elevation to project the flat heatmap (Optional)

Outputs

NameTypeAccessDescription
VelocityHeatmapMeshItemFlat, unwelded crisp horizontal pixel-tile matrix
WindVectorsLineListSpatial direction markers
VectorColorsColorListVelocity color map matching lines
StreamlinesCurveListContinuous particle flow paths
VelocityDataTextListRaw velocity values formatted
TagPointsPointListAnchor coordinates for Text Tag
PlainMeshMeshItemOriginal topography mesh without vertex colors
