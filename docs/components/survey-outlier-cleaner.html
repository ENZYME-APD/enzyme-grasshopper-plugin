Site Analysis Nickname: SurveyClean

Overview

Flags survey points that sit above or below the local ground formed by their neighbours (bad shots, Z = 0 points, canopy or roof hits). Uses a robust local plane fit, so slopes are not mistaken for errors. Nothing is deleted: mesh the Clean points and review the Outliers.

Inputs (5)

  • Points (Point): Survey points (e.g. from a DWG survey).
  • Neighbours (Integer): Neighbours used to estimate the local ground around each point. Raise (e.g. 20) for sparse surveys.
  • Threshold (Number): How many local scatters (robust standard deviations) a point may sit off the local ground before it is flagged.
  • Min Deviation (Number): Never flag deviations smaller than this (model units, e.g. metres).
  • Passes (Integer): Re-check passes. Pass 2 ignores points flagged in pass 1, so clustered errors cannot vouch for each other.

Outputs (7)

  • Clean (Point): Points that agree with their neighbours — use these to build the mesh.
  • Outliers (Point): Flagged points, for review.
  • Deviation (Number): Signed distance of every input point from its local ground (+ above, - below).
  • Score (Number): Deviation divided by the local scatter for every input point (flagged when > Threshold).
  • Flags (Boolean): True for every input point that was flagged (same order as Points; use with Cull Pattern).
  • Colors (Colour): Preview colour per input point: grey = clean, red = above ground, blue = below ground.
  • Info (Text): How the component works and how to tune it.
