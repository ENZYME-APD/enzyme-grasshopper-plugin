Facade Module: Balcony

Continuous balconies with 2D wall patterns and intelligent corners.

JSON Masterplan (Beta) Nickname: Mod_Balcony

Overview

Continuous balconies with 2D wall patterns and intelligent corners.

Inputs (15)

  • Bounds (Curve): Boundary curves
  • Heights (Number): Floor heights
  • BayWidth (Number): Width of each bay
  • Depth (Number): Depth of the balcony
  • RailHeight (Number): Height of the railing
  • SillHeight (Number): Height of the sill
  • HeaderDrop (Number): Header drop distance
  • HorizPattern (Text): Horizontal pattern array
  • VertPattern (Text): Vertical pattern
  • BalconyPattern (Text): Balcony pattern
  • FlipDir (Boolean): Flip direction
  • FirstBalcony (Boolean): Toggle first balcony
  • CornerWindow (Boolean): Toggle corner window
  • CornerOffset (Number): Corner offset distance
  • SegLength (Boolean): Segment length bypass

Outputs (7)

  • Slabs (Brep): Slab Breps
  • Railings (Brep): Railing Breps
  • Glass (Brep): Vision glass Breps
  • SolidPanels (Brep): Solid wall Breps
  • HeaderPanels (Brep): Header drop Breps
  • CornerPanels (Brep): Corner window Breps
  • Info (Text): Method, assumptions, simplifications and references.

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. Each curve in a branch is one floor outline; its floor height comes from the matching item of Heights (4.0 m if missing).
  2. Balconies: BalconyPattern (0 and 1) picks which floors get one, repeating; the first floor of each branch is skipped unless FirstBalcony is True. A balcony is a flat ruled surface between the outline and its offset by Depth (FlipDir reverses the side), plus a RailHeight vertical surface on the offset line.
  3. Walls: each outline is split into segments. With SegLength on, segments shorter than 2 × BayWidth become corner pieces; otherwise CornerOffset trims that length off both ends as corner pieces.
  4. Remaining segments are divided into round(length / BayWidth) equal bays; VertPattern digits pick, per floor, which HorizPattern string to use, and its 1 and 0 characters set glass or solid bays in turn.
  5. A glass bay is split into a solid sill (SillHeight), glass, and a header (HeaderDrop) at the top; a solid bay is one full-height panel. Corner pieces are glass with sill and header when CornerWindow is True, else full-height panels on CornerPanels.
  6. The HUD reports areas as length × height for glass, solid, header and corner panels, and outline length × Depth for terrace.

Assumptions

  • Outlines are planar, horizontal and placed at each floor level; units are metres.
  • Outline direction decides the offset side for balconies and so the use of FlipDir.

Simplifications and limits

  • All elements are zero-thickness surfaces: no slab or railing thickness, no frames or mullions.
  • Bay widths are rounded to fit each segment, so they differ from BayWidth.
  • Terrace area is length × Depth, which overstates convex corners and understates concave ones.

Workflow

  • Masterplan or Facade Parser floor outlines and heights -> Bounds and Heights; outputs -> custom previews or BIM export.
