Masterplan Dashboard

Reads a summarized JSON payload from the OOP Masterplan Engine and renders a responsive HUD.

JSON Masterplan (Beta) Nickname: DASH

Overview

Reads a summarized JSON payload from the OOP Masterplan Engine and renders a responsive HUD.

Inputs (14)

  • Run (Boolean): Enable HUD
  • JSON Payload (Text): JSON Payload from OOP
  • Group By Bldg (Boolean): Group By Building
  • Title (Text): HUD Title
  • Suffix (Text): Unit suffix
  • Target Global (Number): Target Global Area
  • Target JSON (Text): JSON containing Targets
  • Size (Number): Font size
  • Anchor (Integer): Anchor (0=TL, 1=TR, 2=BL, 3=BR)
  • Font (Text): Font Face
  • Transparency (Number): Background Opacity (0.0 - 1.0)
  • Offset X (Number): Offset X
  • Offset Y (Number): Offset Y
  • Padding (Number): Padding

Outputs (0)

  • None

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. Parses JSON Payload (keys programs, total_area and buildings) and draws a text table in the foreground of every Rhino viewport while Run is True.
  2. Global mode lists each program area; Group By Bldg lists program areas and a subtotal per building, then a target tracking section. Areas are formatted with two decimals and comma thousands separators in invariant culture, whatever the Windows locale, plus Suffix.
  3. Transparency is the background opacity: 0 = fully transparent, 1 = opaque (default 0.8).
  4. Target JSON maps program names (case-insensitive) to target areas; each program shows value / target and %, in red when it exceeds the target. Target Global does the same for the total.

Assumptions

  • The payload follows the Masterplan Engine summary schema: programs as name to area, buildings as name to an object with programs and total_area.

Simplifications and limits

  • Box width is estimated from character counts, so long labels or proportional fonts can overflow.
  • Display only: there are no outputs.

Workflow

  • Masterplan Engine summary JSON -> JSON Payload; a panel with program targets -> Target JSON.
