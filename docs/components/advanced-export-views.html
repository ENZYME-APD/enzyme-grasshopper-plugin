Advanced Export Views

An automated state-machine exporter that cycles through GH Canvas States and Named Views.

Utilities Nickname: AdvExport

Overview

An automated state-machine exporter that cycles through GH Canvas States and Named Views.

Inputs (17)

  • Run (Boolean): Set to true to start the batch export.
  • Views (Text): Names of the views to export. If empty, exports ALL named views.
  • GH States (Text): Optional. List of GH Canvas State names to cycle through. Wire the 'Current GH State' output to your Canvas State Manager.
  • Display Style (Text): Optional. Name of the Display Mode (e.g., 'Rendered').
  • Layer State (Text): Optional. Name of the saved Layer State to restore.
  • Directory (Text): Folder path to save the images.
  • Prefix (Text): Prefix for the output filenames.
  • Suffix (Text): Suffix for the output filenames.
  • Format (Text): Image format: png, jpg, bmp, tiff.
  • Width (Integer): Image width in pixels.
  • Height (Integer): Image height in pixels.
  • DPI (Integer): Print DPI metadata embedded into the image.
  • Grid (Boolean): Show Grid.
  • World Axes (Boolean): Show World Axes.
  • CPlane Axes (Boolean): Show CPlane Axes.
  • Transparent (Boolean): Transparent background (PNG only).
  • Scale Items (Boolean): Scale line thicknesses and text sizes when capturing at high resolutions.

Outputs (3)

  • Saved Files (Text): Paths to the exported image files.
  • Current GH State (Text): Wire this into the 'Load Name' of the Canvas State Manager component.
  • Info (Text): Component information.
