BranchSizeSplit

Split branches based on their size

Data Nickname: BranchSizeSplit

Overview

Split branches based on their size

Inputs (3)

  • Tree (Generic): Tree to process
  • MinItems (Number): Minimum items threshold
  • MaxItems (Number): Maximum items threshold

Outputs (3)

  • Tree A (Generic): Branches with fewer than minItems items
  • Tree B (Generic): Branches with items between minItems and maxItems
  • Tree C (Generic): Branches with more than maxItems items

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. MinItems and MaxItems are truncated to integers.
  2. Each branch of Tree goes to Tree A if its item count is below MinItems, to Tree B if it is between MinItems and MaxItems (both inclusive), otherwise to Tree C. Paths are kept.

Assumptions

  • Item count includes null items in a branch.

Simplifications and limits

  • None beyond truncating the thresholds to whole numbers.
