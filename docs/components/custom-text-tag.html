Custom Text Tag

Displays a 3D text tag with a custom move vector. Right-click to change the move axis.

Utilities Nickname: CustomTag

Overview

Displays a 3D text tag with a custom move vector. Right-click to change the move axis.

Inputs (6)

  • Plane (Plane): Base plane for text location
  • Text (Text): Text string to display
  • Size (Number): Size of the text
  • Colour (Colour): Colour of the text
  • Justification (Integer): Text justification (0=BL, 1=BC, 2=BR, 3=ML, 4=MC, 5=MR, 6=TL, 7=TC, 8=TR)
  • Move (Number): Distance to move the text along the selected axis

Outputs (0)

  • None

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. Builds a 3D text on Plane with Text, Size and Justification (0 to 8: bottom, middle, top rows; left, centre, right columns).
  2. The plane origin is first moved by Move along the plane's X, Y or Z axis (chosen from the right-click menu, Z by default).
  3. Tags are drawn in the viewport in Colour; there are no outputs.

Assumptions

  • Size is in model units.

Simplifications and limits

  • Preview only: the text cannot be baked or passed on from this component.
