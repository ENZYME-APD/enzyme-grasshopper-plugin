Pixel Image

Creates a tiled surface that pixelates an image with a posterized color palette.

Facade Nickname: PixImg

Overview

Creates a tiled surface that pixelates an image with a posterized color palette.

Inputs (11)

  • Image Path (Text): Absolute path to the image file
  • Grid Cells (Curve): Pre-generated grid cells
  • Mapping Plane (Plane): Optional plane for UV mapping. Auto-detected if empty.
  • Colors (Colour): List of colors mapped to brightness (dark to light)
  • Accent Color (Colour): Accent color
  • Jitter Pct (Number): Jitter percentage (0-100)
  • Accent Pct (Number): Accent percentage (0-100)
  • Inset Factor (Number): Inset factor (0.0-1.0)
  • Bake (Boolean): Bake trigger
  • Bake Name (Text): Bake group/layer name
  • Rotation (Number): Rotate image map in degrees

Outputs (4)

  • panel_mesh (Mesh): Meshes colored by palette
  • panel_colors (Colour): Colors of panels
  • panel_tags (Text): Panel tags
  • panel_geometry (Curve): Panel boundary curves
