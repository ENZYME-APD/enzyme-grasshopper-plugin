Canvas State Manager

Saves and restores the Enabled/Disabled (Locked) and Preview (Hidden) state of all components on the canvas.

Utilities Nickname: StateMgr

Overview

Saves and restores the Enabled/Disabled (Locked) and Preview (Hidden) state of all components on the canvas.

Inputs (6)

  • Save State (Boolean): Button to save current canvas state
  • Save Name (Text): Name to save the state under
  • Load State (Boolean): Button to load the specified canvas state
  • Load Name (Text): Name of the state to load
  • Turn Off New Nodes (Boolean): If true, new nodes added after the state was saved will have preview disabled (hidden).
  • Import JSON (Text): Optional JSON string from another State Manager to merge states.

Outputs (3)

  • Available States (Text): List of saved states
  • Info (Text): Status output
  • Export JSON (Text): Serialized JSON of all saved states. Plug this into 'Import JSON' of another State Manager to share states.
