Method

  1. Draws two buttons on the component. Visit Website opens https://www.weareenzyme.com/ in the default browser; Send Email opens a mailto link to hello@weareenzyme.com with the subject Enzyme Grasshopper Plugin and the Message text as the body.

Assumptions

  • A default browser and mail client are configured on the machine.

Simplifications and limits

  • None beyond opening the links; nothing is sent automatically.
