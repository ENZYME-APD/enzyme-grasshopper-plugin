Flow Accumulation Heatmap

Generates a flow accumulation heatmap by evaluating water paths against mesh vertices.

Site Analysis Nickname: FlowHeat

Overview

Generates a flow accumulation heatmap by evaluating water paths against mesh vertices.

Inputs (4)

  • TerrainMesh (Mesh): The unified topological surface.
  • FlowPaths (Curve): The flow lines generated from the Raindrop Engine.
  • VisualScale (Number): Multiplier to intensify the visual color mapping (Try 1.5 to 3.0).
  • Run (Boolean): Optional. False = skip the analysis and keep showing the last results (cached). Share one toggle with the Analysis Dashboard to switch everything on/off together.

Outputs (3)

  • HeatmapMesh (Mesh): The colored terrain mesh displaying flow accumulation.
  • VertexCounts (Integer): Raw accumulation data mapped 1-to-1 with mesh vertices.
  • Info (Text): Component information and interpretation

Method, assumptions and simplifications

The same notes appear in the component's Info output.

Method

  1. Every vertex of each FlowPaths polyline is snapped to the nearest TerrainMesh vertex, and that vertex's hit count goes up by one.
  2. Intensity = min(1, √(hits / max hits) × VisualScale); vertex colours blend from light grey (220, 220, 220) to blue (10, 50, 255).
  3. VertexCounts gives the raw hit count per mesh vertex, in vertex order.

Assumptions

  • Flow paths are polylines (for example from the Raindrop Engine) that lie on or near the terrain mesh.

Simplifications and limits

  • Counts polyline vertices, not path length or upstream area: densely sampled paths weigh more, and the result is a visual proxy, not a hydrological flow accumulation.
  • Curves that are not polylines are skipped with a warning; each point counts at its nearest vertex however far away it is.

Workflow

  • Raindrop Engine flow lines -> FlowPaths; same terrain mesh -> TerrainMesh.
