FlowHeat

Generates a flow accumulation heatmap by evaluating water paths against mesh vertices.

Description

Visualizes surface runoff concentration using flow paths to generate a color-mapped mesh heatmap.

Inputs

NameTypeAccessDescription
TerrainMeshMeshItemThe unified topological surface.
FlowPathsCurveTreeThe flow lines generated from the Raindrop Engine.
VisualScaleNumberItemMultiplier to intensify the visual color mapping (Try 1.5 to 3.0).

Outputs

NameTypeAccessDescription
HeatmapMeshMeshItemThe colored terrain mesh displaying flow accumulation.
VertexCountsIntegerTreeRaw accumulation data mapped 1-to-1 with mesh vertices.
