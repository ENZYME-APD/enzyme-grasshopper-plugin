TRN-P

Generates highly detailed terrains from 2D curves with procedural noise, contour lines, and forested areas.

Description

A comprehensive terrain generator that applies fractal procedural noise to closed boundary curves. It outputs detailed gradient-colored meshes, main and normal contour lines, and random point distributions restricted to elevation bands and procedural masks for scattering trees.
