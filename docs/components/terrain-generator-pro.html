Terrain Generator Pro

Generates topography with noise-masked procedural forest scattering and strict elevation limits.

Terrain Nickname: TRN-P

Overview

Generates topography with noise-masked procedural forest scattering and strict elevation limits.

Inputs (21)

  • Boundary (Curve): Closed boundary limits
  • MaxHeight (Number): Maximum elevation in meters
  • MinHeight (Number): Minimum elevation in meters
  • Seed (Integer): Randomization seed
  • PatternSizeXY (Number): List of feature sizes in meters
  • PatternHeightZ (Number): List of relative feature strengths
  • ContourStep (Number): Interval for normal contour lines
  • MainStep (Number): Interval for main contour lines
  • Colors (Colour): List of gradient colors based on height
  • Resolution (Integer): Grid density
  • UseSlopeColor (Boolean): Toggle steep slope coloring
  • SlopeColor (Colour): Color applied to sheer cliffs/slopes
  • SlopeAngle (Number): Angle where slope color starts
  • TerrainStyle (Integer): 0 = Realistic Soft Hills, 1 = Ridged/Cellular Pattern
  • Solid (Boolean): Toggle closed mesh extrusion
  • BaseCol (Colour): Color for the extruded solid base section
  • TreeMsk (Number): Coverage mask threshold 0.0 to 1.0
  • TreeDns (Number): Density multiplier inside mask areas
  • TreeSeed (Integer): Dedicated seed for the forest noise map
  • TreeZMin (Number): Minimum relative elevation for trees 0.0 to 1.0
  • TreeZMax (Number): Maximum relative elevation for trees 0.0 to 1.0

Outputs (4)

  • Mesh (Mesh): Gradient colored terrain geometry
  • NormContours (Curve): Standard contour lines
  • MainContours (Curve): Major interval contour lines
  • Trees (Point): Scattered point coordinates for trees
