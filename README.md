# Enzyme Grasshopper Plugin

## Output

The compiled plugin (`enzyme.gha`) will be in `bin/Release/net48/`.

## Usage

Copy the built `.gha` file to your Grasshopper Libraries folder:

- **Windows:** `%APPDATA%\McNeel\Rhinoceros\7.0\Plug-ins\Grasshopper\Libraries`
- **macOS:** `~/Library/Application Support/McNeel/Rhinoceros/7.0/Plug-ins/Grasshopper (b45a29b1-4343-4035-989e-044e8580d9cf)/Libraries/`

## Continuous Integration

This repository includes a GitHub Actions workflow to automatically build the plugin.
